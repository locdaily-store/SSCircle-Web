MINECRAFT ACCOUNT

Hubungkan akun Minecraft

Belum terhubung

Hubungkan Profile SSCircle dengan identitas Minecraft yang diverifikasi server. Jangan pernah memasukkan password Minecraft ke website ini.

⌁
Perlu login password dashboardBuka bagian Keamanan akun terlebih dahulu untuk membuat dan mengelola tautan Minecraft.
Langkah 1: buat kode penghubung

Kode hanya berlaku selama 10 menit dan hanya dapat digunakan satu kali. Pastikan akun Minecraft sudah login dengan benar.

Langkah 2: masukkan perintah di server Minecraft

Buka chat Minecraft di server SSCircle, tempel perintah, lalu kembali ke Profile untuk konfirmasi. Gunakan kode baru jika sudah kedaluwarsa.

Langkah 3: konfirmasi identitas

Server sudah memeriksa akun yang memasukkan kode ini. Pastikan identitas berikut benar sebelum menyimpan.

Jika ini bukan akunmu, batalkan permintaan dan buat kode baru.

✓ Akun Minecraft terverifikasi

Verifikasi ulang password dashboard untuk memutuskan tautan. Statistik historis tidak otomatis dihapus.

Java Premium, Java Non-Premium (AuthMe), dan Minecraft Bedrock (Floodgate) dapat ditautkan jika server sudah mengaktifkan autentikasi yang sesuai.
