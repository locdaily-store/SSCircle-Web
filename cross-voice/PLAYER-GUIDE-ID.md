# Cara menggunakan SSCircle Voice

## Minecraft Java
1. Pasang Simple Voice Chat versi client yang kompatibel dengan server dan versi Minecraft-mu.
2. Masuk server dan periksa pengaturan mikrofon Simple Voice Chat.
3. Bicara langsung kepada pemain dekatmu. Tidak perlu membuka SSCircle Voice untuk Java.

## Minecraft Bedrock
1. Masuk SSCircle melalui Geyser/Floodgate, selesaikan autentikasi sebagaimana aturan server.
2. Di chat Minecraft ketik `/voice link`. Catat kode delapan karakter yang berlaku dua menit.
3. Di browser desktop/HP buka halaman **SSCircle Voice** dan masukkan kodenya.
4. Setelah nama dan avatar Minecraft muncul, tekan **Aktifkan mikrofon** dan beri izin browser.
5. Pilih **Push-to-Talk** (tekan/tahan tombol V atau tombol PTT layar) atau **Voice Activation**.
6. Gunakan **Mute**, **Deafen**, **Whisper**, **Group**, dan kontrol volume sesuai kebutuhan.
7. Tekan **Disconnect** jika selesai. Jika token habis, gunakan `/voice link` untuk kode baru.

**Android/iOS:** beberapa perangkat menghentikan mikrofon browser ketika Minecraft ada di depan. Pengaturan chat Minecraft tidak memberikan akses langsung ke mikrofon Bedrock vanilla. Gunakan perangkat kedua jika browser di background tidak bekerja.

## English quick guide
Java users install Simple Voice Chat on their game client. Bedrock users run `/voice link` in Minecraft, enter the eight-character code on SSCircle Voice, grant microphone access and use Push-to-Talk or Voice Activation. Browser audio running in the background is not guaranteed on iOS or Android.
