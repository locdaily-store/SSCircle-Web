# SSCircle V10.51.1 — Direktori Anggota, Manage Friends & Popup Profil

## Perubahan utama
- Pencarian kini mendukung **ID Anggota publik**, nama tampilan, serta username Minecraft yang telah terhubung. ID publik berformat **SSC-M** + 12 karakter heksadesimal terakhir dari UUID internal keanggotaan (contoh: SSC-M123456789ABC). ID publik **bukan** kode pendaftaran/login, dan tidak dapat dipakai sebagai pengganti kode pendaftaran.
- Di Profile, baris ID Anggota sekarang menampilkan ID publik, bukan petunjuk empat digit kode pendaftaran. Kode pendaftaran tetap privat dan digunakan hanya pada alur autentikasi lama.
- Tombol **Semua member** membuka daftar berpaginasi, 24 anggota per halaman, dengan **Tampilkan lebih banyak**. Hanya pendaftar **Diterima** yang boleh tampil; anggota dengan privasi Pribadi tidak ditampilkan kecuali sudah menjadi teman.
- **Manage Friends** menampilkan tiga tab: Teman, Permintaan masuk, dan Terkirim, masing-masing dengan jumlahnya. Tindakan tambah, terima, tolak, batalkan, dan hapus teman tetap memakai endpoint yang mengharuskan sesi Dashboard dengan password.
- Klik kartu hasil pencarian atau **Lihat Profile** membuka dialog asli (popup overlay), dengan penutupan tombol, klik backdrop, atau Esc. Pop-up mencakup ID publik, avatar, bio yang diizinkan, akun Minecraft, statistik yang dibagikan, penghargaan Season, dan kontrol pertemanan.
- Avatar menggunakan render kepala dari PNG skin Minecraft terverifikasi melalui endpoint privat server. Skin diproses dengan createImageBitmap + canvas (tanpa data URL), dan akan menampilkan logo SSCircle jika skin belum tersedia.
- Pencarian dilindungi rate limit; daftar juga dibatasi, tanpa expose kode pendaftaran, data keamanan, atau statistik tersembunyi.

## Keamanan / kompatibilitas
- Tidak ada perubahan pada struktur tabel D1, server pairing, kredensial HMAC, protokol Minecraft, ataupun JAR Paper/Skin Bridge/Velocity.
- ID publik terikat ke ID submission yang sudah tersimpan. ID lama dari tracking_code tidak pernah digunakan untuk pencarian, dan UUID prefix delapan karakter yang bisa menjadi fallback login lama tidak dipakai.
- Pencarian dan daftar membutuhkan status Diterima **dan** sesi password Dashboard yang masih aktif. Pending, Rejected, Anonymous, dan sesi kode pendaftaran saja tidak mendapatkan daftar.
- Pengecualian privasi: kedua pihak yang sudah berteman dapat tetap melihat profil satu sama lain hingga pertemanan dihapus. Penghapusan memulihkan visibilitas profil Pribadi terhadap mantan teman.
- Tampilkan Semua member bukan enumerasi seluruh pendaftar. Pendaftar Pending/Rejected dan anggota yang tidak mengizinkan profil ditemukan tetap tersembunyi.
- ID publik menggunakan 48 bit UUID dari suffix, sehingga peluang benturan sangat kecil untuk skala SSCircle, namun tidak memberikan jaminan keunikan matematis untuk database berukuran sangat besar. Jangan menggunakannya sebagai credential autentikasi.

## Pemeriksaan sebelum deploy
1. Luluskan keseluruhan GitHub Actions pada SHA commit yang akan dipakai, bukan pada commit lain.
2. Cadangkan Pages production dan database D1. Deploy ke **staging** terlebih dahulu.
3. Ambil ZIP dari workflow yang lulus; upload ZIP Cloudflare ke Pages. Jangan menggunakan source repository ZIP, rahasia lokal, atau folder plugin sebagai paket website.
4. Login dengan dua anggota Diterima. Uji pencarian nama, username, ID publik, pencarian kode pendaftaran (harus tidak menemukan), dan Semua member.
5. Uji anggota Pribadi vs anggota yang mengizinkan pencarian, permintaan teman, terima/tolak, pembatalan, dan hapus pertemanan. Uji pengunjung/pending/ditolak/sesi tanpa password tidak dapat mengakses API sosial.
6. Uji pop-up pada desktop/HP, keyboard Esc, scroll halaman panjang, fallback avatar, serta avatar dari PNG yang dikirim oleh plugin server.
7. Pastikan /api/health melaporkan release 10.51.1, endpoint D1 tersedia, dan Paper /sscircle diagnose tetap normal. Bila staging gagal, rollback Pages saja tanpa menghapus D1, world, maupun credentials pairing.

## Catatan
Perubahan yang dilakukan di sini hanya menambahkan perilaku website. Tidak ada plugin Minecraft baru yang diperlukan. CI hijau tidak menggantikan tes runtime Paper 26.3 + Cloudflare D1 yang sesungguhnya.
