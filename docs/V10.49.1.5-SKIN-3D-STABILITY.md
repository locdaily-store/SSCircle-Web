# SSCircle V10.49.1.5 | Stabilitas tampilan skin Minecraft 3D

## Perbaikan

Model V10.49.1.4 dapat tampil pecah ketika skin mempunyai transparansi pada topi, jaket, lengan atau celana. Renderer WebGL sebelumnya menggambar sisi depan dan belakang lapisan luar sambil menonaktifkan penulisan depth buffer, sehingga urutan lapisan bertabrakan. CSS 3D fallback juga bergantung pada komposit layer browser.

Pada V10.49.1.5, `minecraft-skin-3d.js` memakai **Canvas 2D dengan geometri kubus 3D yang tetap**. Setiap muka kubus dihitung dari model Minecraft, diputar dalam koordinat 3D, disaring berdasarkan arah permukaan, disusun berdasarkan jarak ke kamera, kemudian tekstur atlas skin dipetakan secara affine ke bidang yang terlihat. Model menggunakan kamera ortografis tanpa distorsi perspektif. Gambar dasar dan seluruh lapisan luar (`hat`, `jacket`, `right-sleeve`, `left-sleeve`, `right-pants`, `left-pants`) tetap terpisah dan dapat dinyalakan/dimatikan.

Renderer tidak membutuhkan GPU WebGL, CDN atau pustaka eksternal, serta tetap mendukung skin 64x64 Classic/Slim dan skin 64x32 legacy. Fitur rotasi drag, pinch, wheel, tombol zoom, reset, dan refresh skin tetap dipertahankan.

## Perubahan file

- `minecraft-skin-3d.js`: ganti WebGL/CSS 3D menjadi painter canvas yang depth-sorted.
- `minecraft-avatars.js`: teks kesalahan renderer disesuaikan.
- `my-sscircle.html`, `player-dashboard.css`: cache busting V10.49.1.5.
- `_worker.js`: label release kesehatan V10.49.1.5.
- `tests/minecraft-skin-3d.test.mjs`: tes geometri, UV, lapisan luar dan rasterizer.
- `tests/profile-ui.test.mjs`, `tests/runtime-health.test.mjs`, `tests/browser_skin_3d.py`: tes versi dan smoke browser.

## Instalasi

1. Simpan backup ZIP situs V10.49.1.4 dan gunakan **Cloudflare Pages staging** dahulu.
2. Upload ZIP `SSCircle-Cloudflare-Upload-V10.49.1.5.zip` dengan cara Direct Upload; seluruh file website ada di root ZIP.
3. Periksa `/api/health` hingga release `10.49.1.5`.
4. Lakukan Ctrl+Shift+R atau buka jendela incognito agar `minecraft-skin-3d.js?v=10.49.1.5` termuat.
5. Masuk Profile -> Akun Minecraft Saya -> Lihat skin. Putar 360°, zoom, dan coba tombol Lapisan luar.
6. Pastikan avatar dan statistik lain tetap normal.

**Tidak diperlukan perubahan JAR SSCircle Player Sync, Skin Bridge 10.49.1.3, SQL D1, R2, secret, atau autentikasi.** Ini hanya perbaikan presentasi.

## Pengujian dan keterbatasan

- `node --test tests/*.test.mjs`: 150/150 lulus.
- `python tests/browser_skin_3d.py`: lulus pada Chromium desktop dan ukuran seluler dengan skin 64x64 contoh; validasi tombol layer, zoom, dan rendering canvas.
- Belum diuji dengan PNG asli akun SSCircle di browser milik pengguna. Hasil di website produksi tetap memerlukan pengujian setelah deployment.

Rollback cukup memasang ulang ZIP V10.49.1.4; jangan menghapus database atau plugin.
