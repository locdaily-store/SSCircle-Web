# SSCircle V10.49.1.7 | Automatic Server Pairing

## Pemasangan baru (tanpa menyalin secret)

1. Upload ZIP Cloudflare yang sesuai ke Cloudflare Pages. Pertahankan binding DB dan secret SESSION_SECRET serta ADMIN_PASSWORD yang sudah ada. Tidak perlu menambahkan SSCIRCLE_LINK_SERVER_SECRET baru untuk instalasi otomatis.
2. Jalankan Paper 26.3 dengan Java 25 dan pasang SSCircle Player Sync V10.49.1.7 serta SkinBridge bila diperlukan.
3. Isi hanya endpoint pada plugins/SSCirclePlayerSync/config.yml dengan URL HTTPS website SSCircle. Opsional: atur auto-pairing.server-name.
4. Pada server yang belum memiliki server-secret.txt, plugin membuat file privat server-pairing.properties berisi identitas instalasi dan token acak. Jangan unggah file ini ke website atau GitHub.
5. Setelah Paper menyambung, jalankan /sscircle pair sebagai OP untuk melihat kode verifikasi 12 karakter.
6. Admin Control -> Minecraft Sync -> Server Terhubung: pilih permintaan sesuai ID/nama dan masukkan kode yang sama persis seperti di Paper. Setujui.
7. Plugin memeriksa status secara asynchronous sekitar 30 detik sekali, mengambil kredensial HMAC khusus server, dan menyimpannya secara privat.
8. Jalankan /sscircle diagnose, /sscircle status, serta /ssskin status bila menggunakan addon. Pemain tetap memakai kode tautan dari Profile website untuk menghubungkan akun masing-masing satu kali.

## Keamanan dan kompatibilitas

- **Pendaftaran server bukan autentikasi**. Permintaan pertama hanya berstatus pending; tidak dapat mengirim statistik, skin atau identitas dan tidak dapat menautkan akun sampai disetujui oleh Admin Control.
- **Persetujuan dua sisi**: kode 12 karakter hanya diberikan kepada instalasi Paper yang memegang bootstrap token. Kode tidak ditampilkan oleh API daftar server sehingga admin harus mengecek langsung di server yang sebenarnya.
- **HMAC khusus tiap server**: pengiriman mempunyai header X-SSC-Server-Id, signature terikat path + timestamp + nonce + JSON raw, dan backend membaca secret hanya ketika status server aktif.
- **Pencabutan instan**: admin dapat mencabut sebuah server tanpa mengubah kredensial server lain. Plugin lama yang tidak memiliki server ID tetap dapat memakai SSCIRCLE_LINK_SERVER_SECRET yang lama.
- **Instalasi lama tidak diubah diam-diam**: jika server-secret.txt sudah ada atau environment SSCIRCLE_LINK_SERVER_SECRET terisi, plugin mempertahankan metode lama. Jangan menghapus file lama untuk sekadar upgrade.
- **Tidak ada migrasi destruktif**. Tabel minecraft_pair_servers dibuat secara aditif, tanpa mengubah AuthMe, statistik, dunia, inventori, password pemain atau tautan akun.
- **Rate limit**: maksimal 6 pendaftaran per jam per IP, 500 polling per jam per IP, 12 tindakan admin per jam per IP dan 100 permintaan pending. Masa berlaku persetujuan 24 jam.
- **Pemulihan**: jika pairing kedaluwarsa, periksa server yang benar lalu jalankan /sscircle pair reset CONFIRM sebagai OP. Jika instalasi lama sudah pernah disetujui, cabut terlebih dahulu dari Admin Control.
- **Website tanpa secret lama**: D1, SESSION_SECRET dan ADMIN_PASSWORD tetap diperlukan. Auto Pairing mengganti penyamaan secret server secara manual, bukan menghapus pengamanan.
- **Batas V10.49.1.7**: ringkasan telemetry global masih memuat heartbeat terbaru dari server yang mana pun. Daftar Server Terhubung sudah merekam lastSeenAt per server.

## Checklist staging

- [ ] Instalasi baru tanpa server-secret.txt menghasilkan kode /sscircle pair.
- [ ] Permintaan pending tidak dapat mengirim statistik, mengklaim akun, atau sinkronisasi skin.
- [ ] Kode salah atau kedaluwarsa ditolak; kode benar disetujui hanya satu kali.
- [ ] Kredensial muncul hanya di file privat server setelah persetujuan.
- [ ] Plugin terhubung setelah restart tanpa persetujuan ulang.
- [ ] Koneksi website HTTPS gagal dapat dicoba ulang tanpa memblokir main thread.
- [ ] /sscircle diagnose berhasil; statistik hanya untuk akun yang sudah ditautkan dan dikonfirmasi.
- [ ] FastLoginPlus/Non-Premium, AuthMe, Bedrock/Floodgate (jika terpasang) tetap memakai bukti sesi lama.
- [ ] SkinBridge membaca kredensial core setelah pairing berhasil tanpa perlu server-secret.txt.
- [ ] Revoke di Admin Control langsung menyebabkan HMAC per-server ditolak.
- [ ] Server lama tetap bekerja dengan server-secret.txt dan backend secret Cloudflare yang cocok.
- [ ] Pengujian 20–50 pemain, TPS/MSPT dan durable stats-queue di server staging.

## Rollback

Backup konfigurasi Paper dan D1 sebelum update. Bila ada masalah, rollback ZIP Cloudflare dan JAR Paper secara berpasangan, serta pertahankan file privat server-pairing.properties untuk pemulihan setelah perbaikan. Jangan menghapus atau mereset UUID, AuthMe, database maupun world sebagai cara troubleshooting.
