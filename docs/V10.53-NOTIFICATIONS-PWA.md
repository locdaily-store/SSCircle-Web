# SSCircle V10.53 • Notification Center dan PWA

## Perubahan
- Pengumuman resmi SSCircle melalui Admin Control, dengan penerima seluruh pendaftar, anggota diterima, atau ID Anggota tertentu.
- Jadwal publikasi, masa berlaku, tingkat kepentingan, dan pengarsipan pengumuman.
- Pengumuman tidak diduplikasi ke setiap akun. Status baca dan penghapusan tersimpan terpisah menurut anggota.
- Filter Mail Box untuk pengumuman, event, komunitas, status, dan aktivasi; status baca dapat disinkronkan.
- Notifikasi badge ketika pengurus memberikan penghargaan.
- Pengingat event muncul berdasarkan jadwal resmi ketika anggota membuka Notification Center dalam rentang 24 jam atau 1 jam menjelang kegiatan. Tidak ada push notification OS ketika aplikasi ditutup.
- Pengaturan notifikasi pada Profile tanpa menu utama baru.
- PWA installable di browser yang mendukung manifest, HTTPS, dan service worker; halaman offline hanya untuk informasi umum.

## Keamanan dan kompatibilitas
- Semua API berita resmi memerlukan otorisasi pengurus. Pengaturan penerimaan memerlukan sesi Profile anggota yang aman.
- URL tautan hanya dapat menuju rute SSCircle yang ditentukan.
- Pesan kode aktivasi tetap tidak tersimpan di cache PWA. Service worker tidak menyimpan API, Admin, Profile, Mail Box, atau halaman berisi data pribadi.
- Tabel baru bersifat idempoten: notice_preferences, notice_announcements, notice_receipts. Tidak ada reset basis data.
- Tidak ada modifikasi plugin Minecraft atau tugas berkala pada main thread Paper.

## Pemasangan
1. Gunakan ZIP Cloudflare yang dihasilkan GitHub Actions, lalu unggah sebagai Direct Upload Cloudflare Pages.
2. Pertahankan binding D1 serta secret website yang sudah digunakan.
3. Buka website menggunakan HTTPS, lalu pilih **Pasang SSCircle** jika browser menawarkan instalasi. Di iOS, pilih **Bagikan → Tambahkan ke Layar Utama**.
4. Masuk ke Admin Control → Pusat Notifikasi, lalu kirim pengumuman uji.
5. Masuk sebagai anggota dan verifikasi notifikasi, status baca, pengaturan penerimaan, dan pengingat event.

Pengingat saat aplikasi ditutup memerlukan layanan push dan penjadwal terpisah. Pages Advanced Mode tidak memiliki Cron Triggers bawaan; tidak ada klaim push atau pengingat terjadwal di latar belakang dalam rilis ini.
