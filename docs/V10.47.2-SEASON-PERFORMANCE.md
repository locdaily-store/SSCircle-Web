# SSCircle V10.47.2 — Statistik Season & Performa Paper

## Yang diperbaiki
- **Paper low-TPS:** pembacaan `Statistic.MINE_BLOCK` sekarang **dibatasi per tick**, default **24 kategori blok setiap tick** untuk seluruh plugin (bukan 24 per pemain). Pemain masuk ke antrean pengambilan, lalu diproses bergantian. Ini mengurangi potensi spike ketika 20–50 pemain online. Efek di hosting tetap perlu diuji dengan spark/timings; tidak ada klaim TPS pasti stabil tanpa pengukuran.
- **Antrean aman:** antrean tetap pada file privat `plugins/SSCirclePlayerSync/stats-queue.properties`, satu snapshot terbaru per identitas (maksimum 1024), identitas tidak terverifikasi diabaikan. Penulisan file dialihkan ke thread I/O khusus dan dikumpulkan tiap 10 detik. Restart bersih menunggu penulisan hingga tiga detik. Pada crash mendadak, perubahan maksimal interval flush terakhir bisa hilang.
- **Jaringan:** HTTPS tetap async, retry dengan exponential backoff sampai 5 menit, pengiriman lebih lama tidak boleh menghapus snapshot baru. File antrean V10.47.0 tetap dapat dibaca oleh versi ini.
- **Efisiensi data:** snapshot tidak diantrikan lagi jika angka pemain tidak berubah; setiap request yang diperlukan masih ditandatangani HMAC dan melewati validasi penghubung akun.
- **Profile:** lima kartu dengan ikon SVG lokal, ukuran responsif, warna lembut, pilihan Season / Sepanjang masa, tanggal sinkron, dan tampilan kosong yang tidak mengarang data.

## Season Archive terintegrasi
1. Buka **Admin Control → Season Archive & Hall of Fame**. Buat dahulu sebuah Season.
2. Di bagian **Statistik Minecraft per Season**, pilih Season aktif. Simpan semua perubahan Admin Control.
3. Backend menyimpan **waktu aktivasi dari server**, bukan dari browser. Sampel yang diambil sebelum aktivasi tidak masuk ke Season baru.
4. Snapshot pertama di Season baru menjadi **baseline** (0 untuk seluruh metrik Season). Sampel berikutnya menambah selisih statistik nyata. Season lama tetap ada.
5. Apabila statistik vanilla mereset setelah reset world, progres segmen baru ditambahkan pada total Season dan Sepanjang masa. Data total historis tidak ditimpa angka reset.
6. Setiap perubahan Season membuat periode statistik berbeda berdasarkan ID Season dan timestamp aktivasi. Mengaktifkan Season lama kembali tidak menimpa periode sebelumnya.
7. Pada Profile, pemain bisa memilih statistik Season yang sudah direkam atau **Sepanjang masa**. Arsip Season tidak dihapus saat pergantian.

**Batasan:** data sebelum fitur statistik dipasang tidak bisa direkonstruksi secara akurat untuk Season lama. Baseline Season baru dihitung dari snapshot pertama setelah aktivasi. Season yang belum menerima snapshot tidak menampilkan angka palsu. Belum ada Leaderboard publik otomatis untuk angka-angka ini.

## Pengaturan di plugins/SSCirclePlayerSync/config.yml
Pertahankan endpoint, secret, dan autentikasi yang telah berhasil. Tambahkan atau ubah:

```yaml
stats-sync:
  enabled: true
  interval-seconds: 300
  block-reads-per-tick: 24
  queue-flush-seconds: 10
```

`block-reads-per-tick` dibatasi internal 4–96. Semakin kecil nilainya, semakin ringan beban tick per interval tetapi semakin lama seluruh pemain tersampel. `queue-flush-seconds` dibatasi 3–60 dan diproses oleh thread disk terpisah.

## Langkah pemasangan
1. **Backup world, playerdata, plugins/SSCirclePlayerSync, dan D1**. Pengaturan `online-mode` dan AuthMe/Floodgate tidak perlu diubah.
2. Deploy Cloudflare Pages ZIP **V10.47.2** terlebih dahulu pada Production. D1 melakukan migrasi tabel `minecraft_stat_progress` secara **aditif**, tanpa menghapus statistik lama.
3. Matikan Paper dan ganti JAR SSCircle lama dengan **SSCircle-Player-Sync-Paper-10.47.2.jar**. Jangan hapus `server-secret.txt`, konfigurasi autentikasi, dan file antrean statistik.
4. Restart Paper. Jalankan `/sscircle diagnose`, `/sscircle sync` untuk OP, kemudian `/sscircle status`. Pengambilan statistik berlangsung bertahap, sehingga `/sscircle sync` bukan berarti semua angka selesai dibaca pada tick yang sama.
5. Login Profile SSCircle dan periksa statistik/tanggal sinkron. Di Admin Control pilih Season jika ingin mengaktifkan statistik per Season.
6. Uji di salinan server: Premium, Java AuthMe, Bedrock, reset world, perubahan Season, kehilangan akses HTTPS sementara, serta restart mendadak dan restart normal.

## Pertimbangan Cloudflare
- Plugin tetap mengirim **satu snapshot per akun yang berubah**, biasanya per lima menit. Belum ada batching beberapa akun per HTTP request pada V10.47.2.
- D1 menambah satu tabel kecil untuk pelacakan raw counters + total per Season, selain tabel statistik dan receipt sebelumnya. Penulisan ke D1 meningkat jika Season aktif, jadi pantau Workers requests dan D1 rows written; jangan menganggap kuota Free pasti cukup dalam semua skenario.
- Protokol HMAC, timestamp, nonce, serta bukti akun tertaut tetap wajib.
- Beberapa statistik saat logout berpotensi sedikit terlambat untuk kategori blok karena plugin mengutamakan TPS daripada memindai seluruh blok secara serentak. Snapshot penuh berikutnya akan memperbaruinya.
