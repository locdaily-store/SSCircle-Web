# SSCircle V10.49.1 — Minecraft Skin & Avatar

## Perubahan dari main V10.49.0

- Profile menggunakan wajah skin dari **akun utama Java Premium yang terhubung dengan bukti login Mojang online-mode**. Tidak lagi memaksa logo SSCircle untuk semua akun Premium.
- Kartu Multi-Account menampilkan wajah tiap akun Java Premium yang memenuhi syarat, dan tombol **Lihat skin** membuka pratinjau badan tampak depan, termasuk lapisan luar untuk format skin 64×64.
- Java `java_offline` (termasuk FastLoginPlus PREMIUM pada sesi campuran) dan Bedrock/Floodgate sengaja tetap menggunakan fallback SSCircle. UUID AuthMe offline dan XUID **bukan** UUID Mojang yang aman untuk lookup. Ini adalah batas keamanan, bukan deteksi lisensi.
- Browser hanya mengambil `GET /api/player/minecraft/skin/{accountId}` dari origin SSCircle. Tidak memanggil API Mojang dari browser, tidak memakai nickname, dan tidak mengirim secret.
- Worker mewajibkan sesi anggota diterima, password Dashboard dan kepemilikan `accountId`. Hanya `provider=java_premium` dengan UUID valid, metadata skin resmi `sessionserver.mojang.com`, dan tekstur dari `textures.minecraft.net` yang boleh diambil. Respons harus PNG berukuran terbatas. Gagal load tidak memutus tautan atau mengubah statistik.
- Tidak ada migrasi D1, reset secret, perubahan UUID, queue, HMAC, nonce, AuthMe, inventory, atau tambahan beban tick Paper. JAR versi 10.49.1 hanya untuk menyelaraskan paket CI dan tidak memerlukan dependency baru.

## Cara memasang di staging

1. Backup D1, konfigurasi dan kunci plugin, AuthMe/FastLoginPlus, `world/playerdata`, serta antrean statistik. Jangan unggah backup atau secret ke GitHub.
2. Review Pull Request V10.49.1 dan jalankan workflow **Periksa dan kemas SSCircle untuk Cloudflare**. Tiga jobs harus berhasil: tes website, build Paper Java 25, dan build Velocity (jika job itu masih diaktifkan).
3. Dari **satu run commit yang sama**, unduh artifact `SSCircle-Cloudflare-Upload` dan `SSCircle-Player-Sync-Paper`. Artifact GitHub berupa ZIP pembungkus; ekstrak hingga menemukan ZIP upload Cloudflare atau JAR Paper yang sebenarnya. Cek isi ZIP Cloudflare: `index.html`, `_worker.js`, `minecraft-avatars.js`, dan `_routes.json` langsung di root.
4. Deploy ZIP ke Cloudflare Pages **staging** yang sudah berisi binding D1 dan secret lama/staging. Pastikan `/api/health` menampilkan `release=10.49.1` dan tidak ada error. Jangan menyalin database production ke staging tanpa prosedur privasi.
5. Jika akan menguji JAR baru, matikan Paper staging, simpan folder `plugins/SSCirclePlayerSync/`, ganti JAR lama (jangan duplikat), lalu start ulang Paper. Cek `/sscircle status` dan `/sscircle diagnose` sebagai OP. Tidak perlu mengganti `server-secret.txt`.
6. Login Profile SSCircle menggunakan password Dashboard, buka **Akun Minecraft Saya**, cek avatar tiap akun dan **Lihat skin** untuk akun Premium yang benar-benar linked. Pilih akun utama lain untuk memastikan gambar utama berubah.
7. Lakukan uji Premium, offline, Bedrock, HTTP error, perangkat HP/desktop dan screenshot. Barulah gunakan prosedur yang sama di production setelah CI hijau dan pengujian staging lulus.

## Checklist pengujian

- [ ] Akun Java Premium online-mode terverifikasi memperlihatkan wajah dan pratinjau skin yang benar.
- [ ] Akun Java AuthMe offline (termasuk `CRACKED`) tidak meminjam skin Mojang dari username sama.
- [ ] Akun Java offline dengan FastLoginPlus `PREMIUM` tetapi UUID identitas masih AuthMe memakai fallback, tidak dipalsukan.
- [ ] Bedrock XUID memakai fallback; plugin Floodgate dan data permainan tidak berubah.
- [ ] Account B menjadi utama, avatar Profile berpindah tanpa memindahkan statistik, inventory atau playerdata.
- [ ] Meminta skin dengan sesi tidak login, tanpa password Dashboard, ID acak, atau milik anggota lain menghasilkan 403/404.
- [ ] URL tekstur tidak valid, gambar berukuran berlebihan, dan kegagalan API Mojang ditolak secara aman; Profile tetap bisa digunakan.
- [ ] Skin format 64×64 dan 64×32 tampil proporsional; mobile portrait tidak overflow.
- [ ] Isi artifact ZIP benar, Paper Java 25 build dan semua Node/browser security tests lulus.
- [ ] Tidak ada kesalahan D1, HMAC/nonce, pergeseran akun, perubahan statistik, atau penurunan TPS di server uji.

## Batasan yang tetap terbuka

- Tampilan skin adalah **2D pixel-accurate**, bukan model WebGL 3D interaktif. Preview menampilkan sisi depan; belum menyediakan rotasi 360° atau aksesori Bedrock.
- Untuk Java offline-mode yang sebenarnya original, perlu jalur bukti UUID resmi yang terpisah dan aman sebelum memakai skin Mojang. Status FastLoginPlus `PREMIUM` sendiri tidak mengubah provider/UUID lama.
- Tidak ada fitur upload avatar custom, sinkron skin Bedrock, atau API publik yang mengungkap identitas anggota. Ini dapat menjadi penambahan opt-in berikutnya.
- Uji otomatis tidak membuktikan API Mojang benar-benar dapat diakses Cloudflare production dan skin akun asli terlihat. Validasi staging tetap wajib.
