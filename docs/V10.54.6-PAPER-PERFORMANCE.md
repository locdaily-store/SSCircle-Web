# SSCircle • Optimasi plugin Paper V10.54.6

Pembaruan ini hanya untuk dua JAR Paper; versi website tetap V10.54.5.
Tidak ada perubahan D1, Player Sync pairing, verifikasi AuthMe, FastLoginPlus atau Floodgate.

## Mengurangi beban CPU
- SSCircle Player Sync membaca blok setiap 2 tick (sebelumnya setiap tick).
  Penghitungan tetap dibatasi 16 pembacaan per pemanggilan atau 4 saat TPS rendah.
  Interval dapat disesuaikan melalui `stats-sync.capture-period-ticks` (1 sampai 10 tick).
- Jika addon SSCircle Skin Bridge tidak terpasang, fallback skin milik core memeriksa satu
  profil setiap 60 tick, bukan 40 tick. Pengiriman HTTP tetap asinkron dengan maksimal 2 aktif.
- SSCircle Skin Bridge memproses seluruh pemain melalui satu antrean dengan satu tugas
  terjadwal, bukan membuat satu tugas tambahan per pemain setiap periode pemeriksaan.
  Antrean berdeduplikasi berdasarkan UUID online dan dibersihkan saat logout.
- Penerbitan skin otomatis ditunda jika TPS satu menit kurang dari 18,0.
  Opsi `skin-sync.pause-on-low-tps` dapat dimatikan bila perlu. Tombol sync manual
  tetap mengikuti batas dua permintaan paralel dan antrean bertahap.
- Pembatasan penggunaan memori, pencatatan antrean statistik secara asinkron,
  checksum file serta retry yang sudah ada tidak diubah.

## Pemasangan
1. Cadangkan folder plugin dan database D1.
2. Matikan Paper 26.3 (Java 25), lalu ganti hanya JAR Player Sync dengan 10.54.6
   dan JAR Skin Bridge dengan 10.49.1.4. Pastikan tidak ada duplikat.
3. **Jangan hapus** `stats-queue.properties`, `server-pairing.properties`,
   `server-secret.txt` dan `config.yml` yang sudah dipakai.
4. Setelan lama tetap berlaku; untuk memakai interval lebih ringan, tambahkan:

```yaml
stats-sync:
  block-reads-per-tick: 16
  low-tps-block-reads-per-tick: 4
  capture-period-ticks: 2
```

5. Jika Skin Bridge terpisah dipasang, atur `skin-sync.pause-on-low-tps: true`
   dan `low-tps-threshold: 18.0` di konfigurasinya. Pada fallback core,
   `skin-sync.profile-scan-ticks: 60` tersedia.
6. Nyalakan Paper; uji `/sscircle status`, `/sscircle sync`,
   `/ssskin status`, pergantian skin, dan statistik di Profile.

## TPS
TPS 20,0 berarti rata-rata waktu tick tetap di bawah 50 ms.
Pengurangan tugas SSCircle membantu, tetapi **bukan jaminan TPS 20,0**.
Lakukan pengukuran MSPT/TPS selama 10–30 menit dengan 20–50 pemain:
catat beban tanpa plugin dan dengan plugin, gunakan spark untuk menelusuri
entity, world generation, dan plugin lain jika TPS menurun.
