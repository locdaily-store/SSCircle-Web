# SSCircle V10.52.4 - Profile dan Komunitas

Rilis ini memperluas fitur komunitas resmi SSCircle tanpa chat pribadi dan tanpa sistem pemblokiran member.

## Perubahan
- Profile dapat memilih Pribadi, Teman saja, Anggota, atau Publik (jika diizinkan pengurus).
- Pengaturan komunitas meliputi izin permintaan teman, jumlah teman, teman bersama, dan tampilan badge.
- Direktori menambahkan pencarian ringan, urut nama/anggota terbaru, dan filter jenis Minecraft.
- Manage Friends menambahkan pencarian lokal pada daftar teman yang sudah dimuat.
- Admin Control mendapat pengaturan permintaan pertemanan, jumlah permintaan menunggu, dan badge resmi bagi anggota yang telah diterima.
- Badge dapat diberikan/dicabut melalui Achievement Manager, muncul di Profile anggota apabila dibagikan.
- Tidak ada perubahan atau polling baru pada plugin Paper, sehingga fitur komunitas tetap diproses oleh Cloudflare.

## Privasi dan penyimpanan
- Endpoint komunitas hanya menerima sesi Dashboard anggota yang tervalidasi.
- Profil Pribadi hanya dapat dilihat pemiliknya. Profil Teman saja hanya bisa dilihat setelah pertemanan diterima.
- Persetujuan visibilitas, jumlah teman, mutual friends, dan badge diperiksa oleh Worker sebelum data dikirim.
- Tabel D1 baru dibuat otomatis secara idempoten: \`member_social_settings\`, \`member_social_policy\`, \`member_community_badges\`. Data lama tidak dihapus.
- Default: menerima permintaan teman, tetapi menyembunyikan jumlah teman dan mutual friends.
- Pengurus dapat membatasi permintaan yang belum dijawab (1-100), default 25.

## Pengujian dan penerapan
1. Jalankan \`npm test\` dan pemeriksaan GitHub Actions lengkap.
2. Pastikan build Cloudflare menghasilkan \`SSCircle-Cloudflare-Upload-V10.52.4.zip\`.
3. Unggah ZIP ke Cloudflare Pages, pertahankan binding D1 dan secret produksi.
4. Login sebagai dua anggota berbeda. Uji empat tingkat privasi, permintaan teman, daftar, filter, dan modal.
5. Uji pemberian badge dari Admin Control, lalu lihat hasilnya pada Profile.
6. Verifikasi tidak ada informasi teknis internal atau detail database yang tampil di halaman umum.

Plugin Player Sync dan Skin Bridge tetap menggunakan rilis kompatibel sebelumnya, tanpa perubahan JAR pada pembaruan ini.
