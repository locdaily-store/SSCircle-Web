# SSCircle V10.49.1.1 — Server Skin Sync + Avatar + Viewer 3D

## Masalah yang diperbaiki

V10.49.1 lama hanya mengizinkan Java `java_premium` mengambil skin melalui Mojang. Akun Java `java_offline` AuthMe, FastLoginPlus mixed-mode dan Bedrock tidak punya URL skin pada Worker, sehingga logo SSCircle tetap muncul, dan tombol **Lihat skin** tidak dirender. Dialog lama juga hanya 2D.

## Perubahan

- **Paper:** `PaperSkinSync` membaca tekstur profil *yang diterapkan di Paper*, setelah AuthMe menyelesaikan login. Jika SkinsRestorer tersedia, adapter opsional memeriksa **skin pilihan pemain dari SkinsRestorer 15** di background, bukan di main thread. Tanpa SkinsRestorer, hanya memakai `PlayerProfile.getTextures()` saat aktif. Mod skin yang **hanya ada di client** tidak bisa dibaca server.
- Plugin tidak menghubungi API Mojang dengan username, tidak memindahkan UUID/akun, dan tidak mengubah authSource. `java_offline` yang original tetap punya identitas AuthMe sendiri, bukan ditingkatkan menjadi Premium.
- Hanya URL skin dari `textures.minecraft.net/texture/{hash}` yang disinkronkan. Server melaporkan identitas `provider/providerId/authSource` yang sebelumnya tervalidasi dan URL/model (`slim`/`classic`) bersama waktu pengamatan, lewat `POST /api/minecraft/skin/refresh` dengan **HMAC SHA256 + timestamp + nonce sekali pakai**. Worker menyimpan metadata di D1 secara aditif, per akun tertaut dan anggota `accepted`.
- **Cloudflare:** `minecraft_account_skins` menyimpan URL tekstur resmi, model, dan timestamp, bukan data PNG di D1. Endpoint `GET /api/player/minecraft/skin/{accountId}` memeriksa login password Dashboard, anggota, dan kepemilikan akun; Worker mengambil PNG dari domain resmi dan memverifikasi format/dimensi/ukuran. `GET /api/player/minecraft/skin-info/{accountId}` memberi model/timestamp. Java Premium online-mode memiliki fallback skin Mojang ketika belum ada snapshot dari Paper.
- **Website:** foto profil utama memakai wajah skin dari akun utama; kartu multi-akun menampilkan avatar per akun. **Lihat skin** muncul untuk semua akun tertaut, termasuk offline/Bedrock, dan membuka modal **3D interaktif berbasis CSS 3D** (bukan library WebGL), dengan putar memakai drag/sentuh/tombol, scroll zoom, reset, dan layer luar (jaket/topi/armor skin 2D, bukan item armor Minecraft). Tidak memakai CDN JS pihak ketiga.
- Saat skin belum tersedia modal menunjukkan petunjuk untuk login ulang atau `/sscircle sync`, bukan menyembunyikan tombol. Kegagalan skin tidak boleh mengubah statistik, voting, akun tertaut, inventory atau playerdata.

## Kinerja dan keamanan

- Pembacaan maksimal **satu profile per 40 tick**; tidak mengambil gambar atau melakukan jaringan di main thread. Maksimal **2 request HTTP bersamaan**; cooldown sukses 15 menit dan retry gagal 1 menit. Hanya URL resmi; tidak membolehkan URL privat, URL arbitrer, query string, redirect, PNG besar, atau respons bukan 64×32 / 64×64.
- SkinsRestorer (opsional) dibaca lewat API publik jika terpasang, pada thread pekerja. Jika tidak tersedia, fallback profil live dari Paper. SkinsRestorer menyimpan pilihan skin, yang mungkin berbeda dari skin sementara yang tampil hanya melalui packet; verifikasi dengan skin asli dalam staging.
- Tabel baru dibuat `CREATE TABLE IF NOT EXISTS`, mempunyai FK `ON DELETE CASCADE` ketika akun di-unlink. Tidak menghapus tabel, mereset secret, data AuthMe, playerdata, inventory, atau statistik Minecraft. Lakukan backup D1 terlebih dahulu.

## Cara pasang

1. Backup D1, semua konfigurasi dan server-secret SSCircle, AuthMe/FastLoginPlus/SkinsRestorer, playerdata, queue statistik, dan world.
2. Deploy **ZIP Cloudflare versi V10.49.1.1** di Pages *staging*. File `index.html`, `_worker.js`, `minecraft-avatars.js`, dan `_routes.json` harus langsung di root. `GET /api/health` harus menunjukkan release `10.49.1.1`.
3. Stop Paper 26.3 Java 25 staging, pindahkan **JAR SSCircle Player Sync lama** (jangan duplikat JAR), salin JAR V10.49.1.1 ke `plugins/`. Pertahankan folder `plugins/SSCirclePlayerSync/`, terutama `server-secret.txt`, `config.yml`, `stats-queue.properties`. Restart sepenuhnya, bukan `/reload`.
4. Pastikan `skin-sync.enabled: true` pada konfigurasi (jika file config lama tidak memiliki opsi ini, default-nya true). Pemain masuk memakai AuthMe, pilih skin pada server (jika ada SkinsRestorer). Admin jalankan `/sscircle sync`, cek `/sscircle status` pada server untuk diagnostik "Skin server". Jika `SKIN_NOT_LINKED`, konfirmasi akun di website dulu.
5. Buka Profile SSCircle dengan **password Dashboard** → **Akun Minecraft Saya**, tekan **Lihat skin**. Avatar utama mengikuti pilihan akun utama. Jika baru mengganti skin, tekan `Muat ulang skin` setelah refresh server berhasil.
6. Uji keamanan dan tampilan di HP, PC dan server staging sebelum mengganti production. Tidak wajib memasang Velocity.

## Checklist

- [ ] Java Non-Premium AuthMe telah login, skin server SkinsRestorer terpasang, Profile menampilkan skin sama dengan server.
- [ ] Java Premium menunjukkan skin sesuai sumber; akun Java offline Premium yang menggunakan FastLogin tidak berubah provider/UUID.
- [ ] Bedrock memakai skin yang tersedia dari profil server; skin client-only yang tidak diekspos Paper tetap fallback.
- [ ] Akun A/B/C masing-masing menampilkan skin berbeda dan memilih akun utama mengganti avatar, tanpa memindahkan statistik.
- [ ] Popup Lihat skin 3D muncul untuk offline/premium/Bedrock dan dapat drag/touch, rotasi, zoom, reset, close. Skin klasik (64×32) dan baru (64×64) dirender.
- [ ] Kode HMAC salah, nonce replay, URL berbahaya, belum tertaut, sesi orang lain dan tanpa password ditolak.
- [ ] Cloudflare down/restart Paper/rejoin dan `/sscircle sync` pulih tanpa membekukan main thread.
- [ ] TPS/MSPT tetap stabil 20–50 pemain; verifikasi runtime SkinsRestorer dan Floodgate dalam server staging nyata.
