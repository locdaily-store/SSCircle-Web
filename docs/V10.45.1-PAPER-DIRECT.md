# SSCircle V10.45.2 • Paper Direct, tanpa Velocity

Dokumen ini untuk **pengujian lokal Windows pada server Paper 26.3**. Plugin Paper baru menggunakan endpoint website SSCircle V10.45 yang sudah ada. Tidak ada statistik otomatis pada versi ini.

## 1. Yang perlu disiapkan

| Perangkat / layanan | Wajib? | Keterangan |
|---|---|---|
| Java JDK 25 | Ya | Jalankan \`java -version\` |
| Paper untuk Minecraft 26.3 | Ya | Unduh dari https://papermc.io/downloads/paper |
| SSCircle-Player-Sync-Paper-10.45.1.jar | Ya | Artifact GitHub Actions, **bukan** plugin Velocity |
| Website SSCircle V10.45 (Cloudflare Pages + D1) | Ya | Gunakan proyek testing, dengan member berstatus Diterima + password dashboard |

## 2. Stop proxy dan rapikan Paper lama

Pada komputer lokal:
1. Matikan Velocity dan Paper yang sedang berjalan. Jika port 25565 sibuk, gunakan \`Get-NetTCPConnection -LocalPort 25565 -State Listen\` untuk mengidentifikasi pemilik port tanpa mematikan semua Java.
2. Backup world \`world\`, \`world_nether\`, \`world_the_end\`, \`plugins\`, dan konfigurasi Paper.
3. Jika sebelumnya Paper memakai port 25566 karena di belakang Velocity, ubah ke 25565.

Contoh:

\`\`\`text
D:\SSCircle-Local\
└── Paper-SMP\
    ├── paper.jar
    ├── server.properties
    ├── config\paper-global.yml
    ├── plugins\
    │   └── SSCircle-Player-Sync-Paper-10.45.1.jar
    └── START-PAPER.bat
\`\`\`

## 3. Pengaturan Paper tanpa proxy

\`server.properties\`:

\`\`\`properties
server-ip=127.0.0.1
server-port=25565
online-mode=true
\`\`\`

\`config/paper-global.yml\`: cari blok asli dan ubah *nilai yang ada*:

\`\`\`yaml
proxies:
  velocity:
    enabled: false
\`\`\`

\`spigot.yml\`: set \`settings.bungeecord: false\`.

**Jangan menghapus world.** Jangan menyalin konfigurasi forwarding lama ke server tanpa proxy. Jangan menyetel \`online-mode=false\` untuk menghindari error login; plugin SSCircle sengaja memblokir identitas tidak terautentikasi. Tidak perlu \`forwarding.secret\`.

## 4. Instal JAR

Unduh artifact JAR dari workflow GitHub Actions yang berhasil, lalu letakkan JAR langsung di \`Paper-SMP/plugins/\`. Pastikan **bukan** \`SSCircle-Minecraft-Link-Velocity-*.jar\`.

Jalankan Paper sekali. Folder \`plugins/SSCirclePlayerSync/\` dan \`config.yml\` akan dibuat. Hentikan server dengan \`stop\`, lalu buka \`plugins/SSCirclePlayerSync/config.yml\`:

\`\`\`yaml
endpoint: "https://DOMAIN-SSCircle-testing.pages.dev"
\`\`\`

Gunakan alamat HTTPS deployment SSCircle yang *benar*, hanya origin/domain tanpa \`/api\`, \`/status\`, \`/my-sscircle\`, path, atau query.

## 5. Konfigurasi Cloudflare + secret

Website memerlukan D1 binding \`DB\`, \`SESSION_SECRET\` dan kredensial admin yang sudah dipakai, serta secret khusus **\`SSCIRCLE_LINK_SERVER_SECRET\`**. Pada Cloudflare pilih proyek staging/testing agar data pendaftar produksi tidak berubah. Lakukan backup D1 sebelum mencoba perubahan.

Buat secret kuat lewat PowerShell:

\`\`\`powershell
$bytes = New-Object byte[] 48
$rng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$rng.GetBytes($bytes)
$rng.Dispose()
[Convert]::ToBase64String($bytes)
\`\`\`

Simpan hasilnya **secara privat**, lalu gunakan nilai yang sama di:
- Cloudflare Pages → Settings → Variables and Secrets → secret \`SSCIRCLE_LINK_SERVER_SECRET\`.
- Windows → **Edit environment variables for your account** → New → Variable name \`SSCIRCLE_LINK_SERVER_SECRET\`; Variable value sama persis.

Setelah menambah variabel Windows, **tutup launcher/terminal lama** dan buka yang baru sebelum menjalankan Paper. Perubahan pada Cloudflare perlu dipastikan aktif pada deployment website yang kamu buka. Secret tidak ditulis dalam konfigurasi plugin, BAT, GitHub, atau chat.

## 6. Menjalankan Paper dengan klik ganda

Simpan \`START-PAPER.bat\` pada folder server yang sama dengan \`paper.jar\`:

\`\`\`bat
@echo off
title SSCircle Paper Localhost
cd /d "%~dp0"
java -Xms1G -Xmx4G -jar paper.jar --nogui
pause
\`\`\`

Jalankan dengan klik dua kali. Jendela console akan terbuka untuk log, tanpa perlu mengetik CMD manual. Minecraft → Multiplayer → Direct Connection → \`127.0.0.1:25565\`.

Jika hanya ingin mengakses server di PC yang sama, **tidak perlu port forwarding router**.

## 7. Tes linking

1. Masuk akun website SSCircle dengan kode pendaftaran anggota **Diterima**; masuk ke Profile menggunakan password dashboard. Akun yang belum aktif harus menjalani verifikasi admin dan aktivasi Mail Box terlebih dahulu.
2. Pada bagian Minecraft, klik **Buat kode penghubung**.
3. Masuk Minecraft Java Premium yang terautentikasi lewat launcher resmi ke Paper localhost.
4. Jalankan \`/sscircle status\`, pastikan konfigurasi siap dan jenis Java Premium.
5. Jalankan \`/sscircle link SC-<kode-asli-website>\`. Kode bukan password, tetapi jangan ditampilkan di layar livestream.
6. Di website, klik **Perbarui status**, tinjau nickname dan jenis akun, lalu **Konfirmasi akun ini**. Baru saat itulah tautan benar-benar dibuat.
7. Uji **Putuskan tautan** menggunakan verifikasi password dashboard.

## 8. Konfigurasi opsional Bedrock

Tambahkan \`Geyser-Spigot.jar\` dan \`Floodgate-Spigot.jar\` ke \`plugins\` Paper, lalu restart; ubah \`auth-type\` Geyser menjadi \`floodgate\`. Lihat dokumentasi resmi GeyserMC untuk port Bedrock yang sesuai versi.

Plugin SSCircle hanya mengakui Bedrock bila API Floodgate membuktikan XUID. Jika tidak tersedia, linking ditolak. JANGAN membuat pengecualian berdasarkan prefix nickname.

## 9. Pemecahan masalah

| Pesan | Tindakan |
|---|---|
| This server requires Velocity | Matikan \`proxies.velocity.enabled\` di Paper dan gunakan port Paper langsung. |
| Can't bind 127.0.0.1:25565 | Ada program lain memakai port. Hentikan Velocity lama terlebih dahulu. |
| \`/sscircle\` tidak dikenali | Cek JAR di \`Paper/plugins\`, cek \`latest.log\`, cek Paper 26.3 + Java 25. |
| Secret tidak terdeteksi | Periksa Windows User Environment Variables, tutup launcher lama, restart Paper. |
| /sscircle status: konfigurasi belum lengkap | Periksa domain HTTPS di \`plugins/SSCirclePlayerSync/config.yml\` dan environment variable. |
| Identitas tidak dapat diverifikasi | Pastikan \`online-mode=true\`, akun Java Premium valid dan plugin login campuran tidak aktif. |
| HTTP 401/403 | Cocokkan secret Cloudflare dan Paper dan jam sistem. |
| HTTP 404/410 | Kode salah/expired/di-cancel atau salah domain website. |
| Website belum bisa membuat kode | Periksa deployment Pages/D1, secret Cloudflare dan login password dashboard. |

## Quick command dan diagnosis baru V10.45.2

- Ketik `/sscircle`, tekan **spasi + Tab**. Muncul `help`, `status`, `link` (dan `reload` hanya untuk OP/admin). Subperintah bisa dipilih melalui autocomplete Minecraft. Contoh: ketik `/sscircle st` lalu tekan Tab.
- Menjalankan `/sscircle` tanpa argumen langsung menampilkan bantuan lengkap.
- `/sscircle status` akan menunjukkan secara terpisah status URL website dan status secret; plugin tidak menampilkan secret ke chat.
- Status **website belum lengkap** berarti endpoint masih placeholder atau secret belum terbaca di proses Paper. URL di `plugins/SSCirclePlayerSync/config.yml` harus berupa HTTPS domain (tanpa /api). Secret `SSCIRCLE_LINK_SERVER_SECRET` harus tersedia di Windows/panel **sebelum** Java Paper dijalankan.
- Status **offline-mode** berasal dari Paper `server.properties: online-mode=false`, bukan kesalahan plugin. Untuk server langsung Java Premium, ubah `online-mode=true`, matikan forwarding Velocity, dan restart total.
- Tidak boleh mencoba melewati pemeriksaan dengan mengganti UUID, nickname, atau mengubah kode plugin agar mengirim status Premium palsu.
- Bila panel server membuat JVM sendiri, variabel lingkungan harus disetel lewat panel atau service manager yang meluncurkan Java. Tidak cukup hanya mengubah terminal yang tidak menjalankan Paper.

- **Belum diujicoba secara langsung pada PC pengguna**; kompilasi CI, kontrak API, dan test unit bukan bukti koneksi server asli.
- **Non-Premium tidak didukung pada versi ini**. Tahap berikutnya membutuhkan plugin login dengan bukti autentikasi per pemain, bukan UUID offline/nickname.
- **Belum ada sinkronisasi playtime, deaths, mob kills, season, ataupun server online status**.
- V10.46 akan menambahkan verifikasi server non-premium yang aman, pengujian Floodgate, health status terukur, dan fondasi Paper sync.
- V10.47 mengirim statistik terverifikasi dengan penyimpanan antrean dan idempotency, V10.48 admin monitoring, V10.49 profil dan skin.
