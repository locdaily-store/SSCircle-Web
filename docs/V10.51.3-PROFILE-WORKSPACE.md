# SSCircle V10.51.3 — Profile Workspace dan Member Panels

## Perubahan halaman Profile
- Jarak aman dari header situs, pada desktop dan ponsel, tanpa mengubah header halaman lain.
- Kartu Profile tetap utuh; setiap kategori sekarang dibuka pada panel yang sama: **Profile**, **Pengaturan akun**, **Minecraft**, dan **Komunitas**. Di dalam kategori, pengguna memilih subbagian tanpa menggulir melewati seluruh kartu lain.
- Kartu yang disembunyikan Admin Profile Studio tetap tersembunyi. Perubahan layout disinkronkan ke navigasi. Bagian Security tidak dapat disembunyikan oleh admin.
- Preview di Admin Control sekarang memakai navigasi kategori serupa dan hanya menampilkan data contoh.

## Member Directory dan Manage Friends
- Tombol ikon kaca pembesar membuka atau menutup search bar; Enter mengirim pencarian.
- **Semua member** dan **Manage Friends** memakai panel terpisah, sehingga daftar tidak menumpuk dan masing-masing memiliki kotak scroll responsif.
- Daftar semua member tetap memakai pagination dari backend, daftar friends tetap memakai tab Teman / Permintaan masuk / Terkirim.
- Popup detail anggota dan konfirmasi permintaan pertemanan tetap seperti sebelumnya.
- Hak akses tidak berubah: hanya member Diterima dengan sesi password Dashboard dapat memakai fitur sosial; profil Pribadi tidak dibuka untuk orang lain.

## Stabilitas CI
- Workflow validasi memakai tes Node lintas-file secara berurutan (`--test-concurrency=1`) untuk mengurangi kompetisi sumber daya fixture SQLite/PBKDF2 pada runner.
- Output pengujian gabungan menjadi ringkas dan menampilkan nama tes yang gagal, jika ada, tanpa menumpahkan stack kode panjang.
- Tes browser baru memeriksa navigasi desktop/tablet/HP, perpindahan kategori, serta fallback saat kartu disembunyikan. Tes browser social ditambah untuk ikon pencarian dan pergantian panel.

## Instalasi dan pemeriksaan
1. Cadangkan deployment Cloudflare Pages dan D1 sebelum mengubah produksi.
2. Pastikan job `Periksa dan kemas SSCircle untuk Cloudflare` pada SHA terbaru lulus lengkap; gunakan ZIP dari run tersebut, bukan ZIP source repository.
3. Unggah ZIP ke Pages **staging** lebih dulu; pertahankan DB, SESSION_SECRET, dan ADMIN_PASSWORD tanpa perubahan.
4. Cek `/api/health` menunjukkan release `10.51.3`.
5. Login anggota Diterima dengan password; uji keempat kategori dan subbagian dengan desktop serta ponsel.
6. Di Komunitas: buka search bar via ikon, cari ID SSC-M, buka popup, pilih Semua Member, lalu Manage Friends; pastikan pergantian panel tidak memengaruhi pertemanan.
7. Cek privasi memakai akun Pribadi, akun Anggota, anggota Pending/Rejected, serta sesi tanpa password.
8. Cek Admin Control Profile Studio, pindah/hide kartu, lalu ulangi navigasi Profile. Jika staging gagal, rollback Pages saja tanpa menghapus data atau kredensial.

Tidak ada perubahan plugin Paper/Velocity/SkinBridge, pairing secret, atau skema D1 pada rilis ini. Pengujian CI tidak menggantikan pengujian Cloudflare + D1 produksi dan Minecraft sebenarnya.
