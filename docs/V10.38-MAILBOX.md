# SSCircle V10.38: Mail Box, Aktivasi, dan Voting

## Yang berubah
- Semua perubahan V10.37 yang belum masuk GitHub dibawa bersama tahap Mail Box.
- Anggota yang telah **Diterima** dapat membuka `/mailbox` dan meminta aktivasi dari My SSCircle.
- Setiap permintaan langsung menghasilkan pemberitahuan di Mail Box. Setelah identitas diverifikasi melalui admin, undangan 24 jam sekali pakai secara otomatis dikirim ke kotak masuk. Jika verifikasi sudah dilakukan sebelumnya, kode langsung dikirim setelah permintaan.
- Undangan disimpan dengan HMAC untuk aktivasi; salinan yang dibaca di Mail Box terenkripsi AES-GCM dengan kunci turunan Secret server. Tidak ada plaintext token di database.
- Admin Control > Kelola Pemain > Login & Security memiliki aksi “Verifikasi & kirim kode ke Mail Box”. Admin tidak perlu melihat atau menyalin kode aktivasi.
- Hasil Cek Status tetap di halaman yang sama. Tombol Voting hanya muncul jika dibuka dan tidak pernah dipicu otomatis.
- Admin Control > Voting memiliki sakelar “Buka akses Voting”; URL langsung dan API pun ditolak saat dimatikan, bukan hanya menyembunyikan tombol.
- Perbaikan teks publik/editor agar tidak memunculkan label infrastruktur atau database internal.

## Keamanan dan batasan
**PENTING:** kode pendaftaran merupakan bearer credential. Mail Box saat ini masih dibuka dengan sesi kode pendaftaran sebelum akun aman diaktifkan. Mail Box bukan faktor autentikasi kedua. Karena itu, penerbitan kode aktivasi membutuhkan verifikasi identitas independen oleh admin. Akun Minecraft tidak boleh otomatis ditautkan hanya berdasarkan kode pendaftaran atau password yang diperoleh lewat Mail Box ini. Tahap berikutnya harus menyediakan verifikasi kepemilikan yang lebih kuat, seperti alamat email terverifikasi, passkey, atau pemeriksaan dalam Minecraft.

Pemulihan password setelah akun diaktifkan juga memerlukan verifikasi ulang oleh admin. Tidak ada pengiriman email eksternal; semua pesan tersimpan di situs.

Cloudflare Workers Free memiliki batas CPU; PBKDF2 harus diuji di staging dan penggunaan berbayar atau penyedia autentikasi terpisah mungkin diperlukan. Secret server harus tetap sama jika ingin membaca pesan terenkripsi lama.

## Instalasi
1. Simpan cadangan database SSCircle sebelum deploy.
2. Buat deployment staging menggunakan paket Cloudflare V10.38.
3. Uji permintaan kode dengan anggota Diterima, pending, dan rejected.
4. Pastikan permintaan tanpa verifikasi hanya mengirim notifikasi status menunggu. Admin memverifikasi pemohon menggunakan jalur resmi berbeda dari kode pendaftaran.
5. Setelah admin menyetujui, Mail Box menampilkan pesan dengan tombol “Tampilkan kode”. Copy ke My SSCircle > Keamanan Akun.
6. Matikan Voting di Admin Control, uji `/voting` dan `/api/voting` tidak bisa dibuka; aktifkan kembali dan tes normal.
7. Pantau metrik dan log deploy; jangan membuka fitur Minecraft Linking hingga autentikasi sudah teruji.
