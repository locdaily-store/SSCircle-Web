# SSCircle V10.48.0: Minecraft Sync Monitoring

## Tujuan
Memberi pengurus SSCircle pemantauan sinkronisasi tanpa harus membuka log Paper setiap kali. **Tidak menjalankan perintah Minecraft apa pun dari browser secara langsung**, tidak membuka port kontrol server dan tidak mengubah autentikasi Java Premium, Java AuthMe, ataupun Bedrock/Floodgate.

## Fitur
- **Admin Control → Minecraft Sync**: akun Minecraft yang sudah ditautkan, akun tanpa snapshot statistik, total snapshot tertunda (laporan plugin), pemain online yang **terakhir dilaporkan**, backlog pembacaan statistik, status kirim terakhir, plugin version, estimasi TPS 1 menit, serta riwayat perubahan status.
- Filter nama akun / anggota dan status statistik. Akun dibuat dari `minecraft_accounts` yang sudah dikonfirmasi, bukan dari nama yang diketik pemain secara bebas.
- Status **belum ada laporan**, **laporan baru diterima** (maksimal 6 menit), **laporan terlambat** (hingga 20 menit), dan **status belum diketahui**. Jangan menyamakan status belum diketahui dengan offline.
- Heartbeat setiap 120 detik dari plugin → Cloudflare. HMAC-SHA256, timestamp berlaku 90 detik, nonce anti-replay, data maksimal 1,5 KB, validasi angka dan kode laporan, dan tidak ada penyimpanan secret mentah.
- Log perubahan status saja, bukan setiap permintaan, untuk mengurangi tulis D1; riwayat bertahan maksimal 14 hari bila pembersihan periodik berjalan.
- **Minta sinkronisasi**: Admin dapat mengajukan satu `sync_now` berumur 10 menit; permintaan diambil melalui heartbeat plugin (HTTPS outbound), dijalankan di main thread menggunakan antrean pengambilan V10.47.2, lalu dianggap selesai ketika plugin melapor balik pada heartbeat berikutnya. Ada jeda permintaan baru dua menit dan rate limit 8/jam per pengirim.

## Instalasi
1. Backup database Cloudflare D1, `plugins/SSCirclePlayerSync/`, dan folder world/playerdata.
2. Deploy ZIP Cloudflare **V10.48.0** ke Production `sscircle.pages.dev`. Pastikan binding D1, `SESSION_SECRET`, `ADMIN_PASSWORD` dan `SSCIRCLE_LINK_SERVER_SECRET` tetap ada. Database melakukan migrasi aditif: `minecraft_sync_status`, `minecraft_sync_events`, `minecraft_sync_commands`.
3. Matikan Paper, lalu ganti JAR SSCircle Player Sync sebelumnya dengan V10.48.0. Pertahankan AuthMe, PacketEvents, Geyser/Floodgate, `config.yml`, `server-secret.txt` dan file antrean.
4. Tambahkan tanpa menghapus pengaturan lama:
```yaml
sync-monitor:
  interval-seconds: 120
```
5. Nyalakan Paper; jalankan `/sscircle status` sebagai OP. Tunggu heartbeat awal, buka **Admin Control → Minecraft Sync** lalu klik **Muat ulang**.
6. Untuk menguji perintah dari website, klik **Minta sinkronisasi** ketika laporan plugin baru diterima. Perintah akan diambil pada heartbeat berikutnya (sekitar 2 menit pada default), statistik diambil bertahap, lalu pengurus dapat memeriksa status dan Profile.

## Keamanan dan batasan
- Semua endpoint `/api/admin/minecraft/sync*` memerlukan cookie admin aktif. Admin website hanya boleh mengirim `sync_now` yang diprogram dan dibatasi, **tidak** dapat menjalankan konsol atau perintah bebas.
- Telemetri dari Paper menggunakan kunci HMAC linking yang sebelumnya telah dipasang, tidak ada kunci baru yang perlu dikirim lewat chat.
- Riwayat gangguan menyimpan **kode status yang dibatasi** dan deskripsi umum; tidak menyimpan identitas jaringan pribadi, kode tautan, key atau pesan error mentah.
- Tombol tidak menjamin data telah berhasil tersimpan. Ia hanya memasukkan pekerjaan ke antrean; gunakan informasi **terakhir berhasil** untuk verifikasi.
- TPS yang ditampilkan adalah rata-rata satu menit yang terlapor ketika heartbeat berjalan, **bukan** pengukuran kinerja aktual saat ini. Jika Paper tidak dapat membacanya, nilainya **tidak tersedia**, bukan 20 palsu.
- Jika Cloudflare down, plugin tetap berjalan; data statistik tersimpan di antrean lokal. Website mungkin menampilkan status belum diketahui.
- Pengujian GitHub Actions membuktikan API dan build, tetapi belum menggantikan tes dengan pemain Java Premium, Java AuthMe, Bedrock, serta 20–50 pemain online di hosting nyata.
