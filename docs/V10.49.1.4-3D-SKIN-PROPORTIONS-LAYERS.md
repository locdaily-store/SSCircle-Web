# SSCircle V10.49.1.4 · Perbaikan bentuk karakter dan lapisan luar skin 3D

## Ringkasan

Versi ini **khusus frontend Profile** dan dirancang di atas website V10.49.1.3 yang sudah berhasil menampilkan skin dari D1. Endpoint skin, autentikasi HMAC, database, identitas, statistik, dan plugin Paper tidak berubah.

### Masalah lama

1. Viewer V10.49.1.3 menggunakan perspektif CSS (`perspective:850px`) dan skala pada elemen yang juga berotasi. Saat zoom, bagian tubuh yang lebih dekat ke kamera terlihat membesar relatif terhadap bagian di belakang sehingga model terasa gepeng/ketarik.
2. Sisi-sisi lapisan kedua hanya diperlebar pada kedalaman, tidak pada lebar/tinggi, sehingga jaket, rambut/topi, dan lengan luar dapat bersinggungan dengan model dasar.
3. Tidak ada pilihan untuk menyalakan/menyembunyikan lapisan luar.

### Perbaikan

- `minecraft-skin-3d.js` baru: renderer WebGL 1.0 lokal berbasis **proyeksi ortografis**. Zoom hanya mengubah satu nilai *pixels-per-unit* yang identik untuk seluruh sumbu. Piksel tekstur memakai **NEAREST** (tanpa blur) dan tidak mengunduh script/library pihak ketiga.
- Fallback native CSS3D juga **ortografis** (`perspective:none`) jika WebGL diblokir atau GPU tidak tersedia. Jadi fitur tetap bisa diputar di perangkat tanpa akselerasi grafis.
- Ukuran bagian tubuh mengikuti pixel unit: kepala 8×8×8, badan 8×12×4, lengan Classic 4×12×4, lengan Slim 3×12×4, kaki 4×12×4.
- **Layer kedua** benar-benar dipisahkan dan sedikit lebih besar dari badan untuk semua sisi: topi/rambut, jaket, lengan kanan/kiri, celana kanan/kiri. Legacy 64×32 tetap mendukung lapisan topi.
- Lapisan luar memakai transparansi aslinya, bisa ditoggle melalui **Lapisan luar: Aktif/Nonaktif**. Tombol putar kiri/kanan, reset, zoom +/−, roda mouse, keyboard, drag, dan pinch HP tersedia.
- Viewer menonaktifkan model sebelumnya saat membuka akun lain agar tidak tertukar antar-akun; tidak ada perubahan identitas maupun endpoint.
- Tidak ada animasi/render loop 60 FPS ketika viewer tidak disentuh. Gambar dirender saat tekstur, kamera, zoom, atau ukuran berubah untuk menghemat CPU/GPU.

## File yang berubah

- `minecraft-skin-3d.js` (baru): renderer, mesh 3D, sumber UV tekstur, WebGL + CSS3D fallback.
- `minecraft-avatars.js`: integrasi renderer 3D, kontrol kamera, zoom, lapisan luar, refresh, perlindungan pergantian akun.
- `player-dashboard.css`: kanvas, fallback, dan tombol layer responsif.
- `my-sscircle.html`: memuat file renderer lokal dan menaikkan versi cache-busting.
- `_worker.js`: **hanya** menaikkan string release `/api/health` ke `10.49.1.4`. Tidak ada perubahan endpoint/SQL.
- Pengujian `tests/minecraft-skin-3d.test.mjs`, `tests/browser_skin_3d.py` dan revisi ekspektasi version pada tes lama.

## Instalasi Cloudflare

1. Backup website V10.49.1.3 dan D1 seperti biasa, lalu deploy `SSCircle-Cloudflare-Upload-V10.49.1.4.zip` ke **Cloudflare Pages** project yang sama (uji staging dulu jika ada). Isi ZIP sudah di root, tidak perlu diekstrak sebelum Direct Upload.
2. Pastikan Pages **binding `DB`**, `SSCIRCLE_LINK_SERVER_SECRET`, dan konfigurasi lama masih sama. **Tidak perlu membuat/mengubah tabel D1, R2, Worker secrets, atau plugin Minecraft** untuk versi ini.
3. Buka `https://sscircle.pages.dev/api/health` atau domain project yang digunakan. Nilai `release` seharusnya `10.49.1.4` setelah deployment.
4. Di browser, lakukan hard refresh `Ctrl+Shift+R` (atau refresh ulang pada HP). Buka **Profile → Akun Minecraft Saya → Lihat skin**. Tombol lapisan luar dan zoom baru seharusnya terlihat.
5. Tes satu akun model Classic dan satu Slim bila ada, lihat dari depan/samping/belakang, zoom hingga 2×, matikan dan aktifkan kembali layer luar.

## Diagnosis

- Viewer tetap versi lama: cek apakah deploy yang dibuka punya `/api/health` release `10.49.1.4`, lalu hard refresh; HTML memakai `minecraft-skin-3d.js?v=10.49.1.4` dan `minecraft-avatars.js?v=10.49.1.4`.
- Kotak skin kosong dengan pesan 404/403: itu masalah **sinkronisasi skin/session** V10.49.1.3, bukan renderer baru; cek `/ssskin inspect NAMA` dan sesi Profile.
- WebGL tidak ada: fallback CSS3D tetap bekerja, tidak perlu menginstal aplikasi tambahan.
- Model lama 64×32: hanya lapisan head/hat yang disediakan format tersebut; jaket/lengan/celana kedua memerlukan skin 64×64.
- Bila layer luar tidak terlihat, skin PNG pemain mungkin tidak mempunyai piksel pada area overlay. Coba matikan/aktifkan untuk memastikan.

## Verifikasi build

- Semua tes Node.js saat pembuatan paket: 150/150 lulus.
- Browser Chromium tanpa WebGL: fallback CSS3D diuji dengan PNG 64×64 buatan tes; perubahan layer terlihat, zoom seragam, kontrol model dan tampilan HP berfungsi.
- Jalur WebGL diverifikasi melalui mocked-API unit test; **rendering GPU WebGL pada perangkat/server sungguhan belum diverifikasi**.
- Tidak mengakses D1 production dan tidak mengubah data pemain.
