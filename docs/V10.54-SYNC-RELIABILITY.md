# SSCircle V10.54.5 • Minecraft Sync Reliability & Recovery

## Perbaikan sinkronisasi
- Statistik Paper menggunakan antrean maksimal 1.024 identitas. Saat antrean penuh, data lama dipertahankan; pengurus menerima peringatan dan tidak ada penggantian diam-diam terhadap identitas lain.
- Cache sampel yang dibaca dibatasi maksimal 2.048 identitas agar penggunaan RAM tetap terkendali ketika server lama menyala.
- Penulisan disk asinkron menggunakan satu pekerja yang aktif dan satu salinan antrean terbaru yang menunggu. Pekerjaan disk tidak menumpuk tanpa batas.
- File antrean memiliki checksum SHA-256 serta pergantian file atomik. Format antrean sebelumnya tetap dapat dibaca.
- Jika file antrean gagal divalidasi, file dipindahkan ke arsip `.damaged-*`, bukan dihapus. Jika file tidak dapat diamankan, penulisan baru ditahan agar file lama tidak tertimpa.
- Perintah `/sscircle status` menunjukkan kesehatan antrean, waktu coba ulang, dan pemain yang masih menunggu.
- Admin Control → Minecraft Sync menampilkan peringatan antrean penuh dan masalah file penyimpanan.
- Batas pembacaan blok bawaan menjadi 16 per tick dan 4 ketika TPS rendah. Konfigurasi yang sudah ada tetap dihormati.
- Proses autentikasi AuthMe, FastLoginPlus, Floodgate, Auto Server Pairing, serta validasi snapshot lama tetap dipertahankan.
- Skin Bridge tetap menggunakan batas maksimal dua permintaan aktif dan penjadwalan berkala; tidak diperlukan perubahan JAR.

## Ikon PWA asli
- `assets/sscircle-logo.png` tetap menjadi sumber gambar resmi.
- Ikon SVG untuk pemasangan PWA membungkus byte PNG asli, tanpa gambar pengganti atau kreasi ulang.
- Cache publik PWA diperbarui; API, halaman akun, Mail Box dan Admin Control tidak disimpan untuk akses offline.

## Pemasangan
1. Cadangkan folder `plugins/SSCirclePlayerSync/`, world, playerdata, database D1, dan file `server-pairing.properties` atau `server-secret.txt` apabila ada.
2. Unggah ZIP Cloudflare V10.54.5 dengan menjaga binding dan secret produksi.
3. Hentikan Paper, pindahkan JAR Player Sync versi lama, lalu pasang hanya satu JAR V10.54.5 di folder plugins.
4. Jangan hapus `config.yml`, `stats-queue.properties`, atau file `.damaged-*`.
5. Nilai `block-reads-per-tick` pada konfigurasi lama tidak diganti otomatis. Untuk setelan lebih ringan, gunakan 16 dan 4 pada konfigurasi.
6. Nyalakan Paper, jalankan `/sscircle status`, `/sscircle diagnose`, lalu periksa Admin Control → Minecraft Sync.
7. Lakukan uji jaringan terputus, pengembalian koneksi, restart, pengiriman ulang, login Java Premium/Non-Premium/Bedrock, serta statistik per season.

## Batasan
- Kegagalan disk total dan proses mati paksa sebelum penulisan asinkron selesai masih dapat menyebabkan hilangnya snapshot paling baru. Cadangan tetap diperlukan.
- Uji GitHub Actions membuktikan build dan regresi kode; pengukuran TPS/MSPT dengan 20–50 pemain pada hosting asli tetap diperlukan.
- PWA mendukung instalasi pada browser dan OS yang kompatibel melalui HTTPS. Ini bukan APK native dan tidak menjamin push notification ketika aplikasi ditutup.
