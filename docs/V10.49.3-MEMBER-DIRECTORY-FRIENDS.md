# SSCircle V10.49.3 | Direktori Member, Profil & Pertemanan

## Fitur baru
- Cari Member & Teman di Player Dashboard: pencarian berdasarkan nama tampilan profil dan nama akun Minecraft tertaut yang sudah tersimpan.
- Lihat profil anggota lain: bio (jika diizinkan), nama akun Minecraft, skin PNG server dengan viewer 3D bawaan, statistik per akun/Season jika dibagikan, dan penghargaan Hall of Fame terpublikasi.
- Tambah teman, terima/tolak undangan, batalkan permintaan, dan hapus teman.
- Notifikasi pertemanan privat masuk ke Mail Box penerima; ada tombol Terima teman dan Tolak langsung pada Mail Box popup.
- Profile Studio menerima bagian Cari Member & Teman untuk drag/reorder, masih mendukung urutan profil lama.
- Satu tabel Cloudflare D1 aditif: member_friend_connections. Tidak mengubah playerdata, worlds, data registrasi, statistik lama maupun protokol Auto Server Pairing.

## Privasi dan keamanan
Semua profil tetap Pribadi secara default dan tidak muncul di pencarian. Anggota dapat mengubah Pengaturan profil menjadi Anggota untuk tampil kepada sesama member. Opsi Publik hanya tersedia jika diizinkan admin. Menonaktifkan pembagian profil langsung menghentikan akses detail dan skin dari akun lain, termasuk yang berteman. Menampilkan statistik memerlukan izin showStats yang terpisah.

Pencarian, detail, gambar skin dan aksi pertemanan memerlukan status keanggotaan Diterima serta sesi Dashboard dengan password, bukan cukup kode pendaftaran. Kode registrasi, data kredensial, UUID Mojang pribadi, dan challenge tautan tidak masuk respons direktori. Gambar skin dibaca dari PNG D1 yang sudah disinkronisasi, tanpa pencarian nickname eksternal.

Server menolak self-request, request duplikat, request ke akun privat, dan accept/tolak dari selain penerima yang sah. Permintaan pending dibatasi; setelah penolakan berlaku cooldown tujuh hari sebelum boleh mengirim ulang. Data Mail Box tidak dianggap sebagai bukti status pertemanan, karena hubungan diverifikasi langsung oleh database.

## Cara pakai
1. Upload ZIP Cloudflare ke Pages project yang sama. Pertahankan binding DB serta SESSION_SECRET, ADMIN_PASSWORD dan secret lama lainnya. Jangan reset data D1.
2. Masuk Profile sebagai member Diterima, lalu login memakai password Dashboard.
3. Di Pengaturan profil, pilih Anggota. Aktifkan Tampilkan statistik bila ingin membagikan data game.
4. Di Cari Member & Teman, cari nama profil atau username Minecraft, lalu buka detailnya.
5. Tekan Tambah teman. Pemilik akun tujuan menerima undangan melalui Mail Box dan bisa menerima/menolak di popup Mail Box atau pada panel Permintaan masuk.
6. Setelah diterima, kedua akun muncul sebagai teman. Masing-masing tetap dapat menyembunyikan profil dan menghapus pertemanan.

Skin 3D hanya tampil jika akun Minecraft sebelumnya sudah tertaut dan Skin Bridge telah menyimpan PNG di D1. Statistik yang belum ada tidak direkayasa.

## Kompatibilitas / rollback
Ini pembaruan website Cloudflare, bukan kontrak plugin Minecraft. SSCircle Player Sync dan Skin Bridge V10.49.1.7 tetap kompatibel. Rollback cukup mengembalikan versi deployment Pages yang sebelumnya stabil tanpa menghapus tabel baru, database, akun, atau file secret.
