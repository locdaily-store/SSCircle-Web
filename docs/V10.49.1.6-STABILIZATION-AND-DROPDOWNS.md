# SSCircle V10.49.1.6: stabilisasi + warna menu pilihan

## Perbaikan dropdown

- Semua dropdown asli (`<select>`) di Admin Control, Registration, Cek Status,
  Voting, Event, Season Archive, dan Profile memakai latar warna **solid**.
- Isi dropdown (`<option>`), grup (`<optgroup>`), opsi dipilih dan opsi tidak
  aktif memakai token warna SSCircle. Ini memperbaiki kasus latar putih dan
  teks putih karena popup browser/Windows tidak memadukan background transparan.
- Perubahan warna input dari Admin Control ikut mengubah warna menu pilihan.
- Penggunaan elemen native tetap dipertahankan untuk keyboard, screen reader,
  aksesibilitas dan pemilih di HP. Tampilan popup native pada sistem operasi
  tertentu tetap dapat berbeda dari CSS browser.
- Versi cache `style.css?v=10.49.1.6` diperbarui pada 12 halaman.

## Stabilisasi source dan localhost

- Source Cloudflare V10.49.1.5 dengan skin D1 dan viewer 3D dipertahankan.
- Source Wrangler localhost V10.49.1.5-local.3 digabung menjadi V10.49.1.6-local.4.
- Perintah D1 menggunakan `--local` (tanpa `--preview`); Pages Dev memakai
  `--d1 DB=DB` tanpa `--config`; data lokal tetap `.wrangler/state`.
- GitHub Actions memperbolehkan **hanya** contoh `.dev.vars.example` dan dua
  fixture SQL lokal yang eksplisit, tanpa mengizinkan secret sungguhan.
- Paket ZIP Cloudflare menggunakan allowlist: hanya `_worker.js`, HTML, JS,
  CSS, aset publik, dan file runtime. Source, D1 lokal dan secrets tidak ikut.
- Tidak menggunakan Mock Account Linking. Server Paper sungguhan tetap wajib
  untuk pengujian otentikasi dan sinkronisasi pemain dari ujung ke ujung.

## Cara memasang

### Cloudflare Pages (website online)

1. Backup deployment sebelumnya; upload `SSCircle-Cloudflare-Upload-V10.49.1.6.zip`
   pada project Pages yang sama. Uji staging terlebih dahulu.
2. Verifikasi `/api/health` memiliki `release=10.49.1.6`.
3. Lakukan hard refresh (`Ctrl+Shift+R`) lalu uji dropdown di Admin Control,
   formulir Registration, Voting, dan Profile pada desktop maupun HP.
4. **Tidak perlu migrasi D1**, penggantian secret, atau perubahan JAR/plugin.

### Localhost VS Code

1. Extract `SSCircle-Web-Localhost-V10.49.1.6.zip`.
2. `npm.cmd install`, kemudian `npm.cmd run dev` pada PowerShell Windows.
3. Buka `http://localhost:8788/api/health`, lalu `http://localhost:8788`.
4. D1 localhost menggunakan binding `DB`, `.dev.vars` dan `.wrangler/state`
   pada komputer sendiri, bukan database Cloudflare production.
5. Untuk cek tabel lokal: `npm.cmd run local:check`.
