# SSCircle V10.49.1.2: Skin Delivery Fix & 3D Refresh

## Masalah yang diperbaiki

Screenshot pengguna menampilkan avatar SSCircle/MC dan modal 3D kosong dengan pesan **"Skin belum tersinkron"**. Ini menandakan akun telah tertaut dan tombol sudah berfungsi, tetapi tidak ada `texture_hash` sukses pada D1 untuk akun tersebut. Ini **bukan** bukti bahwa skin tertentu sudah tersedia di server atau bahwa addon telah aktif. Penyebab yang mungkin: addon belum dipasang/loaded, AuthMe belum memverifikasi login, SkinsRestorer tidak memiliki skin tersimpan, plugin tidak dapat membaca tekstur Paper, atau HTTP 401/404/503 saat mengirim.

Pada V10.49.1.1, semua kegagalan ini disembunyikan; HTTP request menggunakan body discarding dan source `SkinsRestorer`/Paper sering mengembalikan kosong tanpa pesan. Perbaikan tidak memalsukan tekstur dari nickname akun Non-Premium.

## Perubahan plugin SSCircleSkinBridge 10.49.1.2

- Integrasi SkinsRestorer 15.x lewat API resminya: `PlayerStorage.getSkinOfPlayer(UUID)` untuk skin tersimpan, lalu `getSkinForPlayer(UUID, username, isOnlineMode)` jika belum ada pilihan langsung, dan `PropertyUtils.getSkinTextureUrl/getSkinVariant`. Tidak mengambil skin Non-Premium dari Mojang hanya bermodalkan nickname.
- Fallback tekstur `PlayerProfile.getTextures()` Paper, diambil **pada main thread**. Resolusi SkinsRestorer dilakukan async. Maksimal dua pembacaan SR bersamaan; pemindaian pemain disebar 20 tick; auto-join diperiksa lagi saat AuthMe/SR selesai login.
- Hasil HTTPS ditangkap (HTTP code plus kode respons aman, tanpa secret/UUID). Hanya HTTP 200 yang dianggap skin berhasil tersimpan. 404 akan dicoba lagi nanti, misalnya jika pemain belum terhubung.
- Perintah OP: `/ssskin status`, `/ssskin inspect <pemain>`, `/ssskin sync <pemain>`, `/ssskin sync` untuk semua pemain online, dan `/ssskin reload`.
- Tidak mengubah Player Sync V10.49.1, statistik, world, inventory, UUID, AuthMe, FastLoginPlus, HMAC, atau nonce.

## Perubahan Cloudflare/Profile

- Membaca dan menampilkan skin server milik akun tertaut termasuk Non-Premium dari D1; setiap akun dipisahkan berdasarkan accountId internal.
- **Fallback khusus Java Premium**: untuk sesi `java_premium` Mojang terverifikasi atau `java_offline` yang mempunyai bukti FastLoginPlus PREMIUM **segar**, website boleh mengambil skin publik Mojang hanya untuk gambar profil. Fallback diberi label jelas **Sumber: Mojang Premium (sementara)** dan ditimpa oleh skin server saat data server datang. Status autentikasi, UUID, dan kepemilikan tidak pernah diubah.
- Tidak pernah mengambil skin Mojang berdasarkan nickname Java Non-Premium, tidak mengubah edisi Java/Bedrock.
- Avatar Profile mengikuti akun utama. Viewer 3D menampilkan Classic/SLIM, lapisan luar, drag/putar/zoom, dan kontrol HP/desktop.
- Saat tekstur gagal, modal menampilkan alasan, bukan kotak kosong; **Periksa skin lagi** mengambil keadaan terbaru tanpa keluar dari Profile. Gambar PNG disajikan sebagai `data:` URL sehingga sesuai dengan CSP `img-src 'self' data:` yang sudah dipakai website.
- Profil dan kartu akun menunjukkan status skin server dan waktu sinkron terakhir; cache JavaScript/CSS diperbarui ke 10.49.1.2.

## Cara pemasangan yang benar

1. **Cadangkan** Cloudflare D1, folder privat `plugins/SSCirclePlayerSync/` termasuk `server-secret.txt`/stats-queue, AuthMe/FastLoginPlus/SR, serta world/playerdata.
2. Deploy ZIP Cloudflare V10.49.1.2 ke **staging** menggunakan Direct Upload, dengan binding D1/secrets yang sama. Periksa `https://DOMAIN/api/health`, harus menampilkan `release: 10.49.1.2`. Halaman Profile dari deployment V10.49.1.2 yang sama.
3. Stop Paper. **Pertahankan** SSCircle Player Sync V10.49.1 yang sudah bekerja. Hapus **hanya JAR lama SSCircleSkinBridge V10.49.1.1** dan pasang addon baru V10.49.1.2. Jangan menimpa atau menghapus file private core. Bila tidak terpasang, gunakan **SkinsRestorer 15.x yang kompatibel dengan server** untuk skin custom Non-Premium. Hanya satu versi addon boleh dipasang.
4. Start Paper penuh. Dari console/operator ketik `/ssskin status`. Periksa apakah `Core aktif: YA`, `Endpoint HTTPS: TERSEDIA`, `Secret: TERSEDIA`, dan `SkinsRestorer: AKTIF` bila kamu memakai skin custom Non-Premium.
5. **Login ke Minecraft dengan akun yang sudah tertaut**. Selesaikan autentikasi AuthMe jika diminta. Pastikan skin custom **benar-benar aktif di server**, bukan hanya skin mod client. Tunggu beberapa detik, lalu OP ketik `/ssskin sync rinxxAsoy` menggunakan **nama Minecraft yang persis benar** atau `/ssskin sync` untuk semua yang online.
6. Tunggu hasil network lalu periksa `/ssskin inspect <namaMinecraft>`. Targetnya `SKIN_TERKIRIM_HTTP_200`. Bila belum 200, lihat tabel diagnosis di bawah sebelum melakukan apa pun ke D1.
7. Buka Profile SSCircle > Akun Minecraft Saya > **Lihat skin** > **Periksa skin lagi**. Avatar kiri akan mengikuti skin akun utama. Jika browser menyimpan JS lama tekan `Ctrl+Shift+R`.

## Diagnosis cepat `/ssskin inspect <pemain>`

| Status | Penyebab dan tindakan |
|---|---|
| `SKIN_TERKIRIM_HTTP_200` | Cloudflare sudah menyimpan hash skin. Kalau UI masih blank, cek `GET /api/player/minecraft/skin/<accountId>` di DevTools Network (bukan screenshot secret). |
| `LOGIN_BELUM_TERVERIFIKASI` | Core belum menganggap sesi AuthMe/Floodgate/Mojang aman. Selesaikan login lalu `/sscircle status`, jangan bypass verifikasi. |
| `SKINSRESTORER_TIDAK_TERPASANG \| PAPER_TIDAK_MEMILIKI_TEKSTUR` | Tidak ada sumber tekstur di server. Pasang/konfigurasi SkinsRestorer jika skin custom Non-Premium. |
| `SKINSRESTORER_BELUM_MEMILIKI_SKIN \| PAPER_TIDAK_MEMILIKI_TEKSTUR` | SR belum menyimpan/menerapkan skin pemain. Gunakan fitur SR untuk memilih skin, lalu sinkron ulang. |
| `SKINSRESTORER_API_TIDAK_KOMPATIBEL` | Periksa versi plugin SR yang terpasang dan gunakan kompatibel API 15.x. |
| `HTTP_404_SKIN_NOT_LINKED` | Identitas yang dibaca core untuk sesi saat ini belum tertaut di D1 website tujuan. Periksa akun tertaut dan endpoint staging vs production, **jangan** mengganti UUID atau menghapus akun secara buta. |
| `HTTP_401_SKIN_SIGNATURE_INVALID` | Kunci HMAC Cloudflare dan core tidak cocok. Pastikan `SSCIRCLE_LINK_SERVER_SECRET` benar. Jangan bagikan nilainya. |
| `HTTP_401_SKIN_SIGNATURE_HEADERS` | Periksa jam mesin dan format header, sistem nonce, serta clock server. |
| `HTTP_503_SERVER_SECRET_MISSING` | Worker Cloudflare belum dikonfigurasi dengan secret skin/link server. |
| `NETWORK_ERROR_HTTPS` | Periksa DNS/firewall hosting dan URL endpoint dari `plugins/SSCirclePlayerSync/config.yml`. |
| `ANTREAN_SKIN` | Lookup tertunda untuk menghindari lag saat banyak pemain online. Coba lagi setelah antrean selesai. |

> **Penting**: `/sscircle sync` adalah perintah sinkronisasi **statistik**, bukan skin. Untuk gambar gunakan `/ssskin sync`.

## Pengujian yang sudah dilakukan

- Node.js: **140/140 tes lulus**, termasuk HMAC, replay nonce, isolasi akun Non-Premium, fallback Premium yang hanya terverifikasi, dan bukti login kedaluwarsa.
- Chromium: avatar Profile, 72 permukaan model 3D dengan skin PNG sintetis 64x64, putar, keadaan gagal, pemulihan melalui tombol refresh, dan tampilan HP 375 px telah diuji.
- Java: addon **dikompilasi Java 21 menggunakan stub Bukkit minimal**; **bukan** kompilasi resmi terhadap Paper API 26.3. Source menyertakan Gradle Java 25 dan GitHub Actions yang akan melakukan build memakai Paper API sebenarnya. **Staging wajib** sebelum menggunakan addon di server production.
- Belum terhubung ke server Minecraft nyata, plugin SkinsRestorer milik pengguna, D1 Cloudflare live, atau bukti texture aktual pengguna. Karena itu kami **tidak mengklaim** sudah melihat skin milik pengguna muncul di production.
