# SSCircle V10.49.0 — Multi-Account Linking (Paper direct + Cloudflare D1)

## Baseline dan batas

- Dibangun dari V10.48.5, Paper 26.3 / Java 25, Cloudflare Pages + D1.
- Akun anggota yang sudah diterima dan login memakai password Dashboard boleh menautkan hingga **3 identitas Minecraft** secara default. Admin Control → Minecraft Sync dapat mengubah batas **1–5** dan mematikan penambahan akun kedua/tambahan.
- Satu identitas `(provider,provider_id)` tidak dapat dimiliki dua anggota. UUID/identitas AuthMe, Floodgate dan bukti FastLoginPlus tidak dikonversi.
- Satu akun Minecraft utama untuk tampilan. Mengubah utama **tidak** memindahkan inventory, playerdata, statistik atau kewenangan login.
- Penghubungan masih menggunakan kode `SC-...` **sekali pakai 10 menit**, `/sscircle link <kode>`, bukti server HMAC + nonce, dan **konfirmasi website**. Hanya satu challenge aktif per anggota.
- Pemutusan tautan sekarang wajib menyebut `accountId` milik anggota serta validasi ulang password Dashboard. Akun Minecraft lain tidak diputus.
- Riwayat per akun yang diputus disalin ke `minecraft_account_stat_archive`. Data historis per anggota sebelum V10.49.0 di `player_stat_snapshots` **tidak dihapus**; terlihat sebagai **Riwayat lama**, tidak ditambahkan ke gabungan untuk mencegah penghitungan ganda.
- `minecraft_account_stat_progress` kini memisahkan total sepanjang masa dan total Season menurut `account_id`. Snapshot pertama Season adalah baseline nol. Reset angka vanilla menambah segmen baru. Statistik gabungan adalah jumlah hanya dari akun yang memiliki data per akun; akun belum tersinkron akan disebutkan.
- AuthMe `CRACKED`/offline adalah deskripsi *sesi*, bukan bukti lisensi Non-Premium. Premium memerlukan FastLoginPlus `PREMIUM` terverifikasi. Bedrock memerlukan XUID Floodgate.
- Voting tidak diberi suara ekstra akibat akun Minecraft tambahan.

## Perubahan teknis

- Endpoint lama `/api/player/minecraft/link/{state,create,cancel,confirm,unlink}` tetap dipakai. `state` menambah `accounts` dan `multiAccount`; `unlink` sekarang membutuhkan `accountId`.
- Endpoint baru `POST /api/player/minecraft/link/primary` memilih akun utama milik sesi anggota.
- Endpoint baru `GET/POST /api/admin/minecraft/multi-settings` (wajib sesi Admin) untuk `enabled` dan `maxAccounts`.
- Profile `/api/player/profile` menambah `accountStatistics`, `statisticsLegacyOnly` dan detail akun beserta `id`.
- D1 menambah tabel **secara aditif** ketika `ensureMemberCenter` berjalan: `minecraft_multi_settings`, `minecraft_link_preferences`, `minecraft_link_audit`, `minecraft_account_stat_progress`, `minecraft_account_stat_archive`; data lama tidak di-reset.
- Plugin Paper **V10.49.0** hanya penyesuaian nomor rilis, karena payload HMAC, identitas dan statistik sudah menyediakan `provider/providerId` dari V10.48.5; tidak ada pemindahan UUID/penambahan polling.

## Pemasangan yang aman

1. **Backup** Cloudflare D1 Production, `plugins/SSCirclePlayerSync/` termasuk `server-secret.txt` dan `stats-queue.properties`, data AuthMe/FastLoginPlus, world dan playerdata. Jangan salin secrets ke GitHub.
2. Ambil **ZIP Cloudflare** dan **JAR Paper** dari satu GitHub Actions `main` run dengan commit rilis yang sama. ZIP Cloudflare harus mempunyai `index.html`, `_worker.js`, dan `_routes.json` di root, bukan di subfolder.
3. Di **staging** Cloudflare Pages dengan D1 dan secret staging, unggah ZIP ke Pages sebagai deployment; buka `/api/health` dan pastikan `release=10.49.0`, D1 ready. Tabel baru dibuat saat endpoint Profile/Link digunakan; pastikan D1 berhasil tanpa error SQL.
4. Stop Paper staging. Sisakan satu `SSCircle-Player-Sync-Paper-10.49.0.jar` dalam `plugins/`. Pertahankan folder `plugins/SSCirclePlayerSync/`, terutama secret, endpoint, config, queue. Restart Paper (jangan `/reload`).
5. OP jalankan `/sscircle diagnose` lalu `/sscircle status`. Pemain mencoba `/sscircle link <kode>` untuk akun kedua, lalu konfirmasi di website.
6. Buka Profile → **Akun Minecraft Saya** → buat kode baru selama slot tersedia. Pilih **Jadikan utama** atau **Putuskan** hanya untuk akun yang dimaksud. Di Statistik pilih filter akun dan Season secara independen.
7. Admin Control → Minecraft Sync → **Multi-Account Linking**: atur batas 1–5 dan izin menambah akun. Mengurangi batas tidak mencabut akun yang sudah ada.
8. Setelah **lulus semua checklist staging** dan backup production terbaru, deploy ZIP ke Cloudflare Production, lalu restart Paper production dengan JAR dari commit yang sama. Periksa kembali `/api/health`, akun lama, statistik, dan TPS/MSPT.

## Batasan dan tindak lanjut

- **Riwayat lama** yang dicatat hanya berdasarkan `application_id` tidak boleh dipaksakan menjadi statistik akun Minecraft tertentu. Ini sengaja ditampilkan terpisah; hanya identitas yang bisa diverifikasi ke rekaman sumber boleh diatribusikan kemudian.
- Pemutusan tautan menyimpan arsip statistik privat untuk audit/recovery, tetapi data akun tidak bisa langsung digunakan lagi tanpa verifikasi linking baru. Pemulihan/transfer antaranggota otomatis tidak didukung (V10.49.2).
- Belum ada perubahan skin otomatis 3D (V10.49.1) atau Leaderboard agregasi (V10.50).
- Lulusnya CI tidak menggantikan pengujian langsung autentikasi FastLoginPlus, AuthMe, Floodgate dan Cloudflare yang digunakan di hosting.
