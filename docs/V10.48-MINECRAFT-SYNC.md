# SSCircle V10.48.1 — Minecraft Sync Monitoring

Monitoring V10.48.0 sudah menjadi bagian dari SSCircle. V10.48.1 menyempurnakan **pencarian dan filter akun di seluruh database**, bukan hanya 100 akun yang sedang tampil, dengan tetap membatasi hasil per halaman untuk menghemat D1.

## Fitur V10.48
- **Admin Control → Minecraft Sync:** status heartbeat plugin, total akun tertaut, akun tanpa statistik, jumlah antrean snapshot, backlog pembacaan, pemain dilaporkan online, sampel TPS satu menit, dan waktu pengiriman sukses terakhir.
- **Daftar akun Minecraft:** filter semua/sudah ada statistik/belum ada statistik dan pencarian berdasarkan nama akun atau nama anggota; V10.48.1 memproses filter di backend untuk semua halaman.
- **Riwayat sinkronisasi:** ringkasan perubahan status yang disimpan maksimal 14 hari, tanpa merekam password, secret, kode linking, IP atau isi chat.
- **Permintaan sinkronisasi dari website:** admin dapat membuat permintaan yang kedaluwarsa setelah 10 menit. Plugin mengeceknya via heartbeat outbound HTTPS setiap 120 detik (bisa diatur). Ini hanya memicu pengambilan data lokal, bukan membuka port RCON.
- **Keamanan:** endpoint administrasi hanya untuk sesi admin, heartbeat memakai HMAC + timestamp + nonce anti-replay, validasi payload, dan request manual dibatasi.
- **Performa:** telemetri ringan, satu heartbeat per interval, tidak memindai statistik per kategori blok; statistik tetap memakai sistem tick-budgeted V10.47.2.
- **Kejujuran status:** tidak ada heartbeat bukan bukti server benar-benar offline; ditampilkan sebagai status belum diketahui.

## Pemasangan
1. Backup D1 dan folder `plugins/SSCirclePlayerSync`, termasuk `server-secret.txt`.
2. Deploy ZIP website yang sesuai V10.48.1, lalu pasang JAR SSCircle Player Sync V10.48.0 atau rilis kompatibel yang menyediakan `PaperSyncTelemetry`. Jangan menurunkan plugin kembali ke V10.47.2 karena versi itu tidak menyediakan heartbeat.
3. Di `plugins/SSCirclePlayerSync/config.yml`, pertahankan konfigurasi statistik/akun yang berjalan; tambahkan:

   ```yaml
   sync-monitor:
     interval-seconds: 120
   ```

4. Restart Paper. Buka **Admin Control → Minecraft Sync**. Gunakan tombol **Muat ulang** untuk membaca status. Ketika ingin mengambil data tanpa menunggu jadwal, pilih **Minta sinkronisasi** dan lihat status antrean.
5. Jika status `Belum ada laporan plugin`, periksa endpoint HTTPS, HMAC secret yang sama dengan Cloudflare Production, versi plugin Paper, dan log konsol.
6. Fitur belum dapat mengukur TPS aktual tanpa pengujian langsung. Pantau TPS dan penggunaan D1 di hosting Minecraft/Cloudflare.

## Batasan
- Pencarian/filter berdasarkan nama dan status beroperasi di seluruh akun yang tertaut, tetapi hasil per halaman dibatasi 100 untuk efisiensi.
- Status `Sudah ada statistik` tidak berarti pemain sedang online; statistik berasal dari snapshot terakhir di database.
- Tombol permintaan sinkronisasi hanya memicu pembacaan statistik. Berhasil mengambil perintah belum berarti semua snapshot diterima Cloudflare.
- Belum ada detail antrean per event atau kontrol pemutusan tautan massal; keduanya dapat direncanakan setelah pengujian V10.48.1.
- Tidak ada secret, nickname sensitif tambahan, atau detail teknis internal yang ditampilkan pada halaman publik.
