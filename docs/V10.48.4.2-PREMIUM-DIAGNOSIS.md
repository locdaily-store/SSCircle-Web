# SSCircle V10.48.4.2 — diagnosis Premium, sesi offline, dan status yang mudah dibaca

## Kesimpulan audit

FastLoginPlus mendefinisikan hasil `FastLoginBukkit.getStatus(UUID)`
untuk **sesi yang sedang online**:
- `PREMIUM`: koneksi pemain berhasil melalui verifikasi Premium
- `CRACKED`: koneksi memakai autentikasi offline. **Bukan bukti bahwa pemilik
  username tidak memiliki lisensi Minecraft original**
- `UNKNOWN`: belum ada bukti sesi, biasanya plugin belum siap atau API bermasalah

SSCircle sebelumnya menerjemahkan `CRACKED` langsung menjadi label
`Minecraft Java Non-Premium` di Profile, sehingga misleading bagi pengguna
launcher resmi yang sedang mengalami gagal verifikasi Premium.

Revisi ini **tidak memalsukan nilai PREMIUM**. Untuk kondisi sesi
`CRACKED`, website kini menampilkan **Minecraft Java (sesi offline)**;
pembacaannya tidak menyimpulkan lisensi. Untuk status `PREMIUM`, website
tetap menggunakan bukti `fastlogin-premium` yang sudah ada dari FastLoginPlus.
Ketika tidak ada bukti yang sah, label tetap `Premium belum terverifikasi`.

## Yang diubah

1. **FastLoginSessionBridge** sekarang menyediakan `inspect()` yang
   memisahkan status login dan penyebabnya: plugin hilang/nonaktif, API tidak
   cocok, gagal dipanggil, belum ada hasil sesi, login offline, dan Premium
   terverifikasi. Data tidak diambil dari nickname atau pencarian Mojang publik.
2. **/sscircle status** kini dikelompokkan dan diberi warna. Pemain melihat
   bagian **Server & Website**, **Akun & Bukti Login**, **Pengiriman ke Website**,
   **Statistik**, dan **Langkah Berikut**. Operator mendapat kondisi
   AuthMe, PacketEvents, ProtocolLib dan FastLoginPlus, hasil pengiriman,
   antrean dan pengaturan `autoLogin`, `autoRegister`,
   `premiumUuid`, `secondAttemptCracked` (tanpa kunci atau data pribadi).
3. **PaperIdentitySync** sekarang membedakan HTTP 404 karena akun belum
   terhubung (`IDENTITY_NOT_LINKED`) dari HTTP 404 karena endpoint Worker
   Cloudflare belum di-deploy (kode `WEB_VERSION_MISMATCH`). Sebelumnya
   keduanya tampak seperti akun belum terhubung, membuat diagnosis keliru.
4. **Website Profile/Admin Control** mengubah label `java_non_premium`
   (kode API lama tetap dipertahankan demi kompatibilitas) menjadi
   **Minecraft Java (sesi offline)**. Admin memperoleh peringatan
   `SESI_OFFLINE_BELUM_PREMIUM` yang menyarankan verifikasi sesi FLP.
5. Menggunakan kontrak HMAC dan skema D1 yang sama: **tidak ada migrasi,
   reset statistik, perubahan UUID, pemutusan tautan, atau overwrite data
   pemain**. Website dan plugin harus dideploy bersama dari build V10.48.4.2.

## Yang harus dilakukan pemilik server

1. Backup folder `plugins/SSCirclePlayerSync` dan file privat
   `server-secret.txt`, `config.yml`, `stats-queue.properties`;
   database AuthMe/FastLoginPlus; `world/playerdata`; serta D1.
2. Deploy Cloudflare Pages ZIP dari build V10.48.4.2 pada Worker yang
   memiliki binding `DB` dan secret `SSCIRCLE_LINK_SERVER_SECRET` lama.
3. Matikan Paper, ganti **satu** JAR SSCircle lama dengan
   `SSCircle-Player-Sync-Paper-10.48.4.2.jar`, lalu restart Paper 26.3.
4. Pastikan hanya ada **satu** FastLogin (disarankan FastLoginPlus),
   AuthMe, ProtocolLib, PacketEvents yang kompatibel. Jika memakai proxy
   Velocity/Bungee, periksa setup FastLoginPlus untuk proxy dan backend.
5. Pemain Java original masuk memakai launcher resmi berlogin Microsoft,
   lalu `/sscircle status`. Cari baris **Sesi FastLoginPlus**:
   - **PREMIUM**: verifikasi sesi sukses. Jika Profile tidak ikut Premium,
     cek pembaruan bukti, secret/Worker, jalankan `/sscircle sync` sebagai OP.
   - **OFFLINE**: FLP memilih sesi offline. Cek data rekam FLP, log startup,
     `autoLogin`, `autoRegister`, `secondAttemptCracked`,
     kompatibilitas ProtocolLib dan AuthMe, serta keberadaan proxy.
     Jangan langsung menyimpulkan pemilik tidak memiliki lisensi.
   - **BELUM DIKETAHUI / API TIDAK KOMPATIBEL**: periksa kelas/versi
     FastLoginPlus, host Paper yang sebenarnya, dan log plugin.
6. Jika output menyebut `WEB_VERSION_MISMATCH`, backend Cloudflare
   belum memiliki endpoint V10.48.4.1+. Jika `IDENTITY_NOT_LINKED`,
   akun memang belum dikonfirmasi. Keduanya memerlukan solusi berbeda.
7. Jangan menjalankan `/flp delete`, `/flp cracked`, menghapus AuthMe DB,
   mengganti `premiumUuid`, menghapus linked D1, atau migrasi UUID tanpa
   backup dan persetujuan pemilik. Mode akun FLP hanya dapat diganti
   setelah kepemilikan diverifikasi.

## Batas hasil pengujian

CI memverifikasi source, kompilasi Paper/Java 25, status API, tampilan,
kompatibilitas Worker dan tes regresi. **CI tidak dapat memverifikasi akun
Minecraft/Microsoft personal pada hosting nyata**. Klaim Premium yang benar
tetap harus dibuktikan oleh FastLoginPlus/handshake, bukan ditebak SSCircle.
